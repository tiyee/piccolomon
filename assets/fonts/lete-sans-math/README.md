# Lete Sans Math

Unmodified regular Lete Sans Math 0.63, embedded by `crates/ryne-services/src/math.rs`
for offline Formulary rendering. No system font installation is needed.

- Upstream: https://github.com/abccsss/LeteSansMath

The macOS bundle ships the notice in `Contents/Resources/lete-sans-math`;
Windows ZIP and MSIX packages ship it in `licenses/lete-sans-math`.
Only the regular math face is used. The upstream LaTeX package, style files,
and limited-coverage bold face are not included.
