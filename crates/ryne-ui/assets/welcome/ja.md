# Ryne へようこそ

この文書は、現在使える書式と操作を紹介する編集可能なガイドです。文字をクリックして編集できます。インライン書式の記号はカーソルが入ると表示され、離れると折り畳まれます。見出しにマウスを重ねるだけでは記号は表示されません。

上部メニューバーの Ryne → 言語で言語を変更すると、未編集の既定ガイドも切り替わります。編集または保存したガイドと、開いたファイルの内容は保持されます。

## 段落と改行

Enter で新しい段落、Shift+Enter で強制改行を挿入します。長い段落はウィンドウ幅に合わせて折り返され、Markdown ソースは変わりません。
これは同じ段落内のソース上の改行です。  
この行の前には、改行直前の空白二つによる強制改行があります。

## 見出し

文書のタイトルは H1、この節は H2 です。ブロックの先頭に一つから六つの `#` を入力し、本文を続けると見出しになります。区切りの空白は必要に応じて補われます。クリックして記号を編集し、カーソルを外すと折り畳まれます。

#### H4 — レベル4の見出し

## インライン書式、リンク、エスケープ

**太字** · *斜体* · ~~取り消し線~~ · __アンダースコアによる太字__ · _アンダースコアによる斜体_ · **太字の中の *斜体*** · [リンクの例](https://example.org)。

クリックまたは矢印キーで書式内に入ると、必要な外側の記号も表示されます。開始記号の後に最初の本文文字を入力すると、有効な終了記号が補完されます。同じ終了文字の入力で補完済み記号を飛び越せます。リンク、インラインコード、単一ドル記号の数式にも対応します。コードとソースモードでは文字どおり入力されます。

インラインコード：`**そのままの文字**` と ``コード内の `バッククォート` ``。コード内の Markdown は解釈されません。バックスラッシュで記号をエスケープできます：\*斜体ではない文字\*、\[リンクではない文字\]。

リンクにはタイトルも付けられます：[Ryne](https://example.org "Ryne のサイト"). 自動リンク：<https://example.org> と <mailto:hello@example.org>。

## リストとタスク

- **太字**を含む箇条書き。
  - 入れ子の項目と数式：$a^2 + b^2 = c^2$。
  - 別の子項目。
- 別の最上位項目。  
  強制改行後も同じ項目です。

1. 番号付き項目。
2. 次の番号付き項目。
   1. 入れ子の番号付き項目。

- [ ] 未完了のタスク。
- [x] 完了したタスク。

箇条書きには `+` と `*` も使えます：

+ 別の箇条書き記号。
* もう一つの記号。

番号付きリストは 1 以外の番号から始められます：

7. 七から始まる項目。
8. 次の項目。

空でない項目で Enter を押すと次の項目が作られ、空の項目では一階層抜けます。Tab / Shift+Tab で項目と子項目のインデントを増減します。同じ階層の先頭項目はインデントできません。Shift+Enter は項目内の改行です。タスクのチェックボックスをクリックすると状態が切り替わり、元に戻す・やり直す操作も使えます。ブロックソースの記号も編集できます。

項目にマウスを重ねるかフォーカスすると、前方の三点メニューから挿入、移動、インデント、削除ができます。削除は子項目も対象です。最上位のリストの左上にある種類ボタンはリスト全体を選択・コピーします。Alt+Enter で現在の項目のメニューを開きます。

## コードブロック

バッククォート、チルダのフェンスと、空白四つのインデントに対応します。フェンスは言語ラベル付きのコード領域に折り畳まれます。Enter はインデントを維持してブロック内で改行します。開始フェンスと任意の言語を入力して Enter を押すと、終了フェンスが補完され、一回で元に戻せます。フェンスと言語はブロックソースで編集します。

```rust
fn main() {
    println!("Hello, Ryne!");
}
```

~~~python
def greet(name):
    return f"Hello, {name}!"
~~~

    **インデントされたコード内の Markdown**
    [リンクもそのまま表示](https://example.org)

- リスト内にもコードを置けます：
  ```json
  {"editor": "Ryne", "ready": true}
  ```

構文強調は Rust、Python、JavaScript/JSX、TypeScript/TSX、JSON、Bash と、`rs`、`py`、`js`、`ts`、`sh` などの別名に対応します。フェンス付きコードの左上の言語メニューで、一般的な言語と既定の `auto` を選べます。`auto` を選ぶとフェンスの情報欄が空になります。自動判定はソースを変更せず強調表示に使われます。手動変更は元に戻せます。他の言語や曖昧なコードは通常表示になります。

## Mermaid 図

```mermaid
flowchart LR
    A[開く] --> B[編集] --> C[保存]
```

閉じた `mermaid` ブロックから離れると図を表示します。プレビューをクリックするか矢印キーで入ると同じソースを編集でき、Escape で折り畳めます。無効、不完全、上限超過の図は診断付きの編集可能なコードとして残ります。

## インライン数式

エネルギー：$E = mc^2$。分数と添字：$\frac{a_1}{\sqrt{b}}$。

一行の LaTeX の両側に `$` を一つずつ置きます。クリックや矢印キーでソースを編集し、離れると数式を表示します。リストや表のセルでも使えます。独立数式（`$$...$$`）、複数行の数式、欠けた字形、未対応の数式はソースのまま残ります。

## 表

| 左揃え | 中央揃え | 右揃え |
| :--- | :---: | ---: |
| **太字のセル** | `code` | 123 |
| 一行目<br>二行目 | エスケープした縦棒：a\|b | $x^2$ |
| 隣は空のセル | | 456 |

セルをクリックして編集します。Tab / Shift+Tab でセル間を移動し、Enter で同じ列の次の行へ移動します。最終行を越えると行を追加できます。Shift+Enter はセル内に `<br>` を挿入します。入力・貼り付けした縦棒は自動でエスケープされます。

セルの三点メニューで列の配置、行列の挿入・移動・削除ができます。Alt+Enter で現在のセルのメニューを開き、矢印キー、Enter、Escape で操作します。区切り記号はブロックソースで編集します。列数が不揃いの表はソース表示です。列幅の変更と複数セルへの TSV 貼り付けは未対応です。

## 引用、画像、区切り線と生のテキスト

引用は `>` を隠し、本文の前に引用アイコン、ブロックに淡い背景を表示します。本文とインライン書式を直接編集でき、構造記号はブロックソースで変更できます。入れ子の引用はインデントを保持します。空でない引用で Enter を押すと引用を継続し、新しい行も背景とインデントを保持します。空の引用行で Enter を押すと一段外に出ます。Shift+Enter は引用内の強制改行です。ソースモードでは通常の改行を挿入します。空の引用と生のテキストは編集可能なソースを保持します。段落を単独で占める HTTP(S)、FTP、`file:`、`data:` の画像はプレビューを表示します。クリックして Markdown を編集し、離れると画像に戻ります。PNG、JPEG、GIF の先頭フレーム、WebP、SVG に対応します。Data URL は Base64 とパーセントエンコードに対応し、ローカルファイルには `file:///...` を使います。読み込み失敗時は破損画像アイコンと取り消し線付きの赤い URL を表示し、256 文字を超える部分は省略記号で示します。クリックすると完全な Markdown を編集できます。本文中の画像はソースを保持します。

## ソース、挿入とファイル

入れ子の内容では、最も外側のブロックの左上にある種類ボタンを使います。ボタンにマウスを重ねると、ブロック全体のソースを編集、選択、コピーできます。Cmd+Shift+B でブロックソース、Cmd+Shift+M で全文ソースを切り替えます。Escape はメニューを閉じるかソースを折り畳みます。ソースモードでは入力と改行をそのまま扱います。

ブロック種類メニューの末尾で「下に追加」または「上に追加」を選び、ブロックの種類を選択します。文書の最初のブロックは「下に追加」のみです。一回で元に戻せます。Escape は種類選択からブロックメニューに戻ります。

文書の下にマウスを重ねると `+` が現れ、各種類のブロックを挿入できます。閉じていない構造は先に完成させてください。

Cmd+O は開く、Cmd+S は保存、Cmd+Shift+S は名前を付けて保存です。Cmd+Z / Cmd+Shift+Z は元に戻す・やり直す、Cmd+A/C/X/V は全選択・ソースをコピー・切り取り・貼り付けです。選択と貼り付けは行やブロックをまたげます。記号、メニュー、ソースの表示では変更扱いになりません。保存は元のソースのバイトと改行形式を保持します。IME の確定は一回で元に戻せる編集として反映されます。

ツールバーの「整形」で Markdown ソース全体を整え、一度で元に戻せます。独立した見出しとタスク記号の空白を規則に従って補い、コード内容、段落の改行、コンテナーのインデントを保持します。保存時の自動整形はありません。
