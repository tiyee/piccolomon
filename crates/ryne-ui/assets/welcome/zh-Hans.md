# 欢迎使用 Ryne（如言）

这是一份可以直接编辑的格式指南，介绍目前可用的格式和操作。点击文字即可编辑；光标进入行内格式时显示 Markdown 标记，离开后收起。仅悬停标题不会展开标记。

在顶部菜单栏的 Ryne → 语言中切换语言，尚未编辑的默认指南也会一起切换。编辑或保存后，它就是你的文档，切换语言会保留内容；打开的文件也会保留。

## 行内格式、链接与转义

**粗体** · *斜体* · ~~删除线~~ · __下划线标记的粗体__ · _下划线标记的斜体_ · **粗体中的 *嵌套斜体*** · [示例链接](https://example.org)。

点击行内格式或用方向键进入，会展开自身和必要的外层标记。输入起始标记后，首个正文字符补齐有效的结束标记；再输入同样的结束字符可以越过。链接、行内代码和单美元公式也支持补全。代码和源码模式按字面输入。

行内代码：`**字面内容**` 和 ``代码中的 `反引号` ``。代码内部不解析 Markdown。使用反斜杠转义标点：\*不是斜体\*，\[不是链接\]。

链接可以带标题：[Ryne](https://example.org "Ryne 网站"). 自动链接：<https://example.org> 和 <mailto:hello@example.org>。

悬停或聚焦条目时，前方三点菜单可插入、移动、缩进、反缩进或删除条目及子项。列表右上角的类型按钮可选择或复制完整列表。Alt+Enter 打开当前条目的菜单。

## 代码块

支持反引号围栏、波浪号围栏和四空格缩进代码块。围栏收起为带语言标签的代码区域。Enter 保留代码缩进并在块内换行。输入起始围栏及可选语言后按 Enter，一次补齐闭合围栏；可一次撤销。通过块源码修改围栏和语言。

```rust
fn main() {
    println!("Hello, Ryne!");
}
```

~~~python
def greet(name):
    return f"Hello, {name}!"
~~~

    **缩进代码中的字面 Markdown**
    [链接也保持字面内容](https://example.org)

- 列表中也可以嵌套代码：
  ```json
  {"editor": "Ryne", "ready": true}
  ```

语法高亮支持 Rust、Python、JavaScript/JSX、TypeScript/TSX、JSON 和 Bash，以及 `rs`、`py`、`js`、`ts`、`sh` 等别名。围栏代码块左上角的语言下拉菜单可选择常见语言和默认的 `auto`；选择 `auto` 清空围栏信息字段。自动识别只影响高亮，不修改源码。手动切换可撤销。菜单中的其他语言及有歧义的代码保持普通样式。

## Mermaid 图表

```mermaid
flowchart LR
    A[打开] --> B[编辑] --> C[保存]
```

光标离开闭合的 `mermaid` 块后显示图表。点击预览或用方向键进入即可编辑同一份源码，Escape 再次收起。无效、不完整或超限的图表保留可编辑代码与诊断。

## 行内公式

能量：$E = mc^2$。分数与下标：$\frac{a_1}{\sqrt{b}}$。

在单行 LaTeX 两侧各写一个 `$`。点击或用方向键进入公式编辑源码，离开后显示公式。列表和表格单元格中也可使用。独立公式（`$$...$$`）、多行公式、缺字和不支持的公式保留源码。

## 表格

| 左对齐 | 居中对齐 | 右对齐 |
| :--- | :---: | ---: |
| **粗体单元格** | `code` | 123 |
| 第一行<br>第二行 | 转义管道符：a\|b | $x^2$ |
| 旁边是空单元格 | | 456 |

点击单元格直接编辑。Tab / Shift+Tab 切换单元格，Enter 移至下一行同列；移过末行时可以追加一行。Shift+Enter 在单元格内插入 `<br>`。输入或粘贴的管道符会自动转义。

单元格三点菜单可调整列对齐、插入、移动或删除行列。Alt+Enter 打开当前单元格菜单，方向键、Enter 和 Escape 用于导航。通过块源码编辑分隔符。列数不齐的表格保留源码；调整列宽和跨单元格 TSV 粘贴尚未提供。

## 引用、图片、分隔线与原始文本

引用隐藏 `>`，正文前显示引用图标，文字块带浅色背景；可直接编辑正文和行内格式，局部源码入口可修改结构标记。嵌套引用保留缩进。非空引用中 Enter 自动续行，新行延续背景和缩进；空引用行 Enter 退出一层，Shift+Enter 插入引用内硬换行。局部或全文源码中 Enter 保持原始换行。空引用草稿、图片和原始文字仍保留可编辑源码，图片尚无图像预览。

## 源码、插入与文件

悬停块类型按钮可打开菜单，编辑局部源码、选择整块或复制源码。嵌套块源码保留容器前缀。Cmd+Shift+B 切换块源码，Cmd+Shift+M 切换全文源码，Escape 关闭菜单或收起源码。源码模式中的输入和换行均按字面处理。

块类型菜单末尾可选择“在下方添加”或“在上方添加”，再选择块类型；文档第一个块仅提供下方。插入可一次撤销，Escape 从类型选择返回块菜单。

悬停文档末尾下方会显示 `+`，可插入上述各类块。未闭合结构需要先补全，才能追加新块。

Cmd+O 打开文件，Cmd+S 保存，Cmd+Shift+S 另存为。Cmd+Z / Cmd+Shift+Z 撤销和重做。Cmd+A/C/X/V 全选、复制源码、剪切和粘贴。选区和粘贴可跨行、跨块。查看标记、菜单或源码不会产生未保存修改；保存保留原始源码字节和换行。输入法确认文字作为一次可撤销编辑提交。

点击工具栏中的“排版”可一键整理全文 Markdown 源码，并可一次撤销。排版按规则修复缺空格的独立标题与任务标记，保留代码正文、段落换行和容器缩进；保存不会自动排版。
