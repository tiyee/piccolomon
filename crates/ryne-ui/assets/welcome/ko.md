# Ryne에 오신 것을 환영합니다

이 문서는 현재 사용할 수 있는 서식과 조작 방법을 소개하는 편집 가능한 안내서입니다. 글자를 클릭하면 편집할 수 있습니다. 커서가 인라인 서식 안으로 들어가면 Markdown 기호가 나타나고 벗어나면 접힙니다. 제목 위에 마우스를 올리는 것만으로는 기호가 펼쳐지지 않습니다.

상단 메뉴 막대의 Ryne → 언어를 바꾸면 아직 편집하지 않은 기본 안내서도 바뀝니다. 편집하거나 저장한 안내서와 직접 연 파일의 내용은 유지됩니다.

## 문단과 줄 바꿈

Enter는 새 문단을, Shift+Enter는 강제 줄 바꿈을 삽입합니다. 긴 문단은 창 너비에 맞춰 자동으로 줄이 바뀌며 Markdown 원문은 변하지 않습니다.
이것은 같은 문단 안의 원문 줄 바꿈입니다.  
이 줄 앞에는 줄 끝의 공백 두 개로 만든 강제 줄 바꿈이 있습니다.

## 제목

문서 제목은 H1이고 이 절의 제목은 H2입니다. 블록 시작에서 `#`을 한 개부터 여섯 개까지 입력하고 본문을 쓰면 제목이 됩니다. 필요한 구분 공백은 자동으로 추가됩니다. 제목을 클릭하면 기호를 편집할 수 있고 커서가 벗어나면 다시 접힙니다.

### H3 — 3단계 제목

#### H4 — 4단계 제목

##### H5 — 5단계 제목

###### H6 — 6단계 제목

Setext H1 제목
=================

Setext H2 제목
-----------------

Setext는 다음 줄의 `=`으로 H1을, `-`으로 H2를 표시합니다. 클릭하면 밑줄을 표시하고 편집할 수 있습니다.

## 인라인 서식, 링크와 이스케이프

**굵게** · *기울임* · ~~취소선~~ · __밑줄 기호로 쓴 굵게__ · _밑줄 기호로 쓴 기울임_ · **굵게 안의 *기울임*** · [예제 링크](https://example.org).

클릭하거나 방향키로 서식 안에 들어가면 필요한 바깥쪽 기호도 펼쳐집니다. 시작 기호 뒤에 첫 본문 글자를 입력하면 유효한 닫는 기호가 완성됩니다. 같은 닫는 글자를 입력하면 자동 완성된 기호를 건너뜁니다. 링크, 인라인 코드, 단일 달러 수식도 지원합니다. 코드와 원문 모드에서는 그대로 입력됩니다.

인라인 코드: `**그대로 표시되는 내용**`과 ``코드 안의 `백틱` ``. 코드 안의 Markdown은 해석하지 않습니다. 역슬래시로 기호를 이스케이프할 수 있습니다: \*기울임이 아님\*, \[링크가 아님\].

링크에는 제목을 넣을 수 있습니다: [Ryne](https://example.org "Ryne 사이트"). 자동 링크: <https://example.org>, <mailto:hello@example.org>.

## 목록과 작업

- **굵은 글자**가 있는 순서 없는 항목.
  - 중첩 항목과 수식: $a^2 + b^2 = c^2$.
  - 또 다른 하위 항목.
- 또 다른 최상위 항목.  
  강제 줄 바꿈 후에도 같은 항목입니다.

1. 순서 있는 항목.
2. 다음 순서 있는 항목.
   1. 중첩된 순서 있는 항목.

- [ ] 아직 끝나지 않은 작업.
- [x] 완료한 작업.

순서 없는 목록에는 `+`와 `*` 기호도 쓸 수 있습니다:

+ 또 다른 목록 기호.
* 하나 더 있습니다.

순서 있는 목록은 1이 아닌 숫자에서 시작할 수 있습니다:

7. 일곱부터 시작하는 항목.
8. 다음 항목.

내용이 있는 항목에서 Enter는 다음 항목을 만들고, 빈 항목에서는 한 단계 빠져나옵니다. Tab / Shift+Tab으로 현재 항목과 하위 항목을 들여쓰거나 내어씁니다. 첫 형제 항목은 들여쓸 수 없습니다. Shift+Enter는 항목 안에서 줄을 바꿉니다. 작업 앞의 체크박스를 클릭하면 상태가 바뀌며 실행 취소와 다시 실행을 지원합니다. 블록 원문에서 작업 기호를 편집할 수도 있습니다.

항목에 마우스를 올리거나 포커스를 두면 앞쪽 점 세 개 메뉴로 삽입, 이동, 들여쓰기, 내어쓰기 또는 하위 항목을 포함한 삭제를 할 수 있습니다. 오른쪽 위 유형 버튼은 전체 목록을 선택하거나 복사합니다. Alt+Enter는 현재 항목 메뉴를 엽니다.

## 코드 블록

백틱 울타리, 물결표 울타리와 공백 네 개로 들여쓴 코드 블록을 지원합니다. 울타리는 언어 표시가 있는 코드 영역으로 접힙니다. Enter는 들여쓰기를 유지하며 블록 안에서 줄을 바꿉니다. 시작 울타리와 선택적인 언어를 쓴 뒤 Enter를 누르면 닫는 울타리가 완성되며 한 번에 실행 취소할 수 있습니다. 울타리와 언어는 블록 원문에서 편집합니다.

```rust
fn main() {
    println!("Hello, Ryne!");
}
```

~~~python
def greet(name):
    return f"Hello, {name}!"
~~~

    **들여쓴 코드 안의 문자 그대로인 Markdown**
    [링크도 그대로 표시됩니다](https://example.org)

- 목록 안에도 코드를 넣을 수 있습니다:
  ```json
  {"editor": "Ryne", "ready": true}
  ```

구문 강조는 Rust, Python, JavaScript/JSX, TypeScript/TSX, JSON, Bash와 `rs`, `py`, `js`, `ts`, `sh` 등의 별칭을 지원합니다. 울타리 코드 왼쪽 위 언어 메뉴에서 일반 언어 또는 기본값 `auto`를 고릅니다. `auto`를 고르면 울타리 정보 칸이 비워집니다. 자동 감지는 원문을 바꾸지 않고 강조에만 사용합니다. 직접 바꾼 언어는 실행 취소할 수 있습니다. 다른 언어와 모호한 코드는 일반 스타일로 표시합니다.

## Mermaid 다이어그램

```mermaid
flowchart LR
    A[열기] --> B[편집] --> C[저장]
```

닫힌 `mermaid` 블록에서 커서가 벗어나면 다이어그램을 표시합니다. 미리 보기를 클릭하거나 방향키로 들어가 같은 원문을 편집하고 Escape로 다시 접습니다. 유효하지 않거나 불완전하거나 제한을 넘은 다이어그램은 진단과 함께 편집 가능한 코드로 남습니다.

## 인라인 수식

에너지: $E = mc^2$. 분수와 첨자: $\frac{a_1}{\sqrt{b}}$.

한 줄 LaTeX의 양쪽에 `$`을 하나씩 씁니다. 클릭하거나 방향키로 들어가 원문을 편집하고 벗어나면 수식을 표시합니다. 목록과 표 셀에서도 사용할 수 있습니다. 독립 수식(`$$...$$`), 여러 줄 수식, 없는 글리프와 지원하지 않는 수식은 원문으로 남습니다.

## 표

| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
| :--- | :---: | ---: |
| **굵은 셀** | `code` | 123 |
| 첫째 줄<br>둘째 줄 | 이스케이프한 파이프: a\|b | $x^2$ |
| 옆은 빈 셀 | | 456 |

셀을 클릭하여 편집합니다. Tab / Shift+Tab으로 셀 사이를 이동하고 Enter로 같은 열의 다음 행으로 이동합니다. 마지막 행을 넘으면 행을 추가할 수 있습니다. Shift+Enter는 셀 안에 `<br>`을 넣습니다. 입력하거나 붙여 넣은 파이프는 자동으로 이스케이프됩니다.

셀의 점 세 개 메뉴는 열 정렬, 행과 열의 삽입·이동·삭제를 제공합니다. Alt+Enter로 현재 셀 메뉴를 열고 방향키, Enter, Escape로 조작합니다. 구분자는 블록 원문에서 편집합니다. 열 수가 맞지 않는 표는 원문으로 남습니다. 열 너비 조절과 여러 셀 TSV 붙여 넣기는 아직 제공하지 않습니다.

## 인용, 이미지, 구분선과 원시 텍스트

인용은 `>`를 숨기고 본문 앞에 인용 아이콘과 블록에 옅은 배경을 표시합니다. 본문과 인라인 서식을 직접 편집하고 블록 원문에서 구조 기호를 바꿀 수 있습니다. 중첩 인용은 들여쓰기를 유지합니다. 내용이 있는 인용에서 Enter는 인용을 이어 쓰고 새 줄에도 배경과 들여쓰기를 유지합니다. 빈 인용 줄에서 Enter는 한 단계 밖으로 나가고 Shift+Enter는 인용 안에 강제 줄 바꿈을 삽입합니다. 원문 모드에서는 일반 줄 바꿈을 유지합니다. 빈 인용, 이미지와 원시 텍스트는 편집 가능한 원문을 유지합니다. 이미지 미리 보기는 아직 제공하지 않습니다.

> **굵은 글자**가 있는 인용.
>
> 같은 인용 블록 안의 두 번째 문단.
> > 중첩 인용.

![이미지 설명](https://example.org/image.png)

---

`***`, `___` 같은 다른 구분선도 인식합니다.
***

<div>원시 HTML은 편집 가능한 원문으로 남습니다.</div>

위의 `---`는 한 줄을 차지하는 구분선이며 앞뒤 문단과 빈 줄로 구분합니다. 불완전하거나 지원하지 않는 구문도 내용을 버리지 않고 편집할 수 있습니다.

## 원문, 삽입과 파일

블록 유형 버튼에 마우스를 올리면 부분 원문 편집, 블록 선택, 원문 복사를 선택할 수 있습니다. 중첩 블록 원문에는 바깥쪽 접두사도 포함됩니다. Cmd+Shift+B는 블록 원문, Cmd+Shift+M은 전체 원문을 전환합니다. Escape는 메뉴를 닫거나 원문을 접습니다. 원문 모드에서는 입력과 줄 바꿈을 그대로 처리합니다.

블록 유형 메뉴 끝에서 “아래에 추가” 또는 “위에 추가”를 선택한 뒤 블록 유형을 고르세요. 문서의 첫 블록에는 “아래에 추가”만 표시됩니다. 한 번에 실행 취소할 수 있으며 Escape는 유형 선택에서 블록 메뉴로 돌아갑니다.

문서 아래에 마우스를 올리면 `+`가 나타나며 각 종류의 블록을 삽입할 수 있습니다. 닫히지 않은 구조는 먼저 완성해야 합니다.

Cmd+O는 열기, Cmd+S는 저장, Cmd+Shift+S는 다른 이름으로 저장입니다. Cmd+Z / Cmd+Shift+Z는 실행 취소와 다시 실행, Cmd+A/C/X/V는 전체 선택·원문 복사·잘라내기·붙여 넣기입니다. 선택과 붙여 넣기는 여러 줄과 블록에 걸쳐 사용할 수 있습니다. 기호, 메뉴와 원문 표시는 문서를 수정하지 않습니다. 저장은 원문 바이트와 줄 바꿈을 유지합니다. IME 확정은 한 번에 실행 취소할 수 있는 편집으로 반영합니다.

도구 모음의 서식 정리를 누르면 Markdown 소스 전체를 정리하고 한 번에 실행 취소할 수 있습니다. 규칙에 따라 독립된 제목과 작업 표시의 누락된 공백을 보완하며 코드 내용, 문단 줄바꿈 및 컨테이너 들여쓰기를 유지합니다. 저장 시 자동으로 서식을 정리하지 않습니다.
