# 腾讯云 Windows 远程桌面控制

在本项目中默认使用本机 Windows App；已有 Microsoft Remote Desktop 连接也可复用。
通过 RDP 进入用户指定的 Windows 服务器，完成其要求的桌面操作并核验结果。
创建或调用技能本身不代表已经连接，也不授权额外的服务器管理操作。

## 确定目标与工具能力

- 从当前请求、已授权的会话上下文和可见连接配置取得目标地址、端口、Windows 用户名、
  网关／VPN 要求，以及登录后要完成的工作。信息足够就继续；存在多个候选服务器或缺少
  必需信息时，只询问缺失项。不要把腾讯云控制台账号当作 Windows 登录账号。
- 优先复用与目标匹配的已保存连接。没有指定端口时可使用 RDP 默认端口 3389；
  非默认端口按客户端的主机与端口格式填写，不扫描其他地址或端口。
- 先检查当前可用工具及其说明。自动控制原生客户端需要能够观察该应用窗口、截图和发送
  鼠标／键盘事件的原生桌面工具；仅有 shell 或浏览器工具不足以完成该流程。
- 若工具明确禁用原生应用控制，报告这一具体限制并交接必要的手动登录步骤；不要通过
  AppleScript、System Events、截图命令或另装自动化程序绕过。用户手动登录后，若仍无
  原生观察与输入能力，就继续提供操作指导，不能声称已控制或核验远程桌面。
- 不因原生工具不可用自行切换 WebRDP、VNC、SSH 或 WinRM。只有用户选择替代方式后，
  才按其可用工具继续。技能不会自行启用权限或安装远控服务。

## 本机客户端登录

1. 读取最新应用窗口状态，打开或选中 Windows App／Microsoft Remote Desktop。
   先识别已有连接与活跃会话，避免重复连接或干扰其他服务器。
2. 有匹配连接时打开该连接；没有时使用界面中的 Add PC／添加电脑入口，填写已确认的
   主机地址。macOS Windows App 通常位于 Devices 页的 `+` 菜单；旧版名称可能不同，
   以当前界面为准。按已知要求设置网关，不猜测网关或域。
3. 使用用户指定的 Windows 账号，保留 `DOMAIN\user`、`user@domain` 等原始形式。
   可使用客户端已有且获授权的已保存凭据；没有时优先让用户在系统密码框直接输入。
   不要求用户把密码发到聊天中，不读取或导出钥匙串，不把密码、令牌写入项目、
   `.rdp`、命令行、日志或截图说明。只有用户要求保存凭据时才使用客户端的系统凭据存储。
4. 连接前核对目标。遇到证书提示时查看目标主机及可用证书信息；按已确认身份或此前
   明确授权继续。主机不匹配、证书变化无法解释或身份不明时停止并说明，不永久关闭验证。
   MFA、验证码及用户必须亲自完成的认证交由用户操作。
5. 等待 Windows 登录完成并重新观察。以远程桌面实际出现、会话目标一致为登录证据；
   保存连接卡片或关闭登录对话框不算成功。需要进一步核对时，可在远程终端只读执行
   `hostname` 和 `whoami`，区分本机终端与远程终端。

如果客户端尚未安装，说明缺少的客户端并提供微软官方安装入口；用户已要求安装时可
在现有权限内继续。不要为直连服务器而添加不相关的工作区或云订阅。

## 操作远程 Windows

- 每组操作遵循“观察当前窗口 → 聚焦远程内容 → 少量操作 → 重新观察”。截图坐标属于
  当前窗口；缩放、全屏、分辨率或滚动变化后重新定位。RDP 内容常是像素画面，不能假定
  本机辅助功能树能定位远程 Windows 控件，也不能用浏览器 DOM 操作原生客户端。
- 发快捷键前确认焦点及客户端的键盘转发设置，区别本机 Command、Windows Ctrl 和
  Windows 键；需要安全注意序列时使用客户端提供的发送入口，以实际菜单为准。
- 输入文字或粘贴前确认远程焦点、键盘布局与输入法；长命令先检查文本和目标，再提交。
  远程命令在服务器执行，本机 shell 命令在本机执行，结果不得混用。
- 文件传输只使用任务需要的路径；本机路径与服务器路径分别核对。共享文件夹或剪贴板
  重定向不可用时先说明，不映射整个本机磁盘或复制无关文件。
- 沿用用户已经授权的任务范围。登录不隐含重启、注销、重置密码、改安全组／防火墙、
  关闭 NLA、覆盖数据或终止其他会话的授权；确需这些操作且未获授权时再询问。
  不关闭可能含未保存内容的应用，不抢占其他用户会话。
- 完成后按用户要求保留或断开连接；断开与注销不同，不能以注销替代关闭连接。

## 故障处理与停止条件

- 凭据被拒绝后停止自动提交，核对用户名格式并让用户检查凭据，避免锁定账号。
- 超时／断线先记录当前可见错误，检查目标、VPN／网关及已知端口。可在条件允许时
  做一次目标端口连通性检查；端口可达不等于身份验证或桌面可用。条件变化后最多自动
  重连一次，仍失败则报告，不循环点击登录。
- 本机直连 RDP 的网络路径与腾讯云 WebRDP 代理不同：检查实际客户端出口或 VPN／网关
  到实例的路径。安全组和 Windows 防火墙应允许相应来源访问配置的 RDP 端口；
  不把 WebRDP 代理地址直接当作本机来源，不为排障开放全网或禁用防火墙。
- 黑屏、会话占用、许可、权限或服务错误先只读诊断，报告原始错误与已做检查。
  不自动重启实例、结束其他会话或修改注册表来尝试恢复。

## 本项目的 Windows 验证

仅当用户要求验证 Ryne 时使用这一节，不能把一般登录任务扩展为构建或发布。

- 先核对目标构建版本与来源，用临时 Markdown 文件验证，避免覆盖用户文档。
- 标题栏拖动、窗口按钮、菜单、编辑／保存等人工操作，按任务逐项观察并记录。
  需要运行 `--smoke-test` 时遵守项目 AGENTS.md，检查失败不得让 panic 穿过原生事件循环。
- 区分真实鼠标／键盘观察、程序化窗口冒烟和编译结果；RDP 下通过的结果只代表该远程
  会话，未检查的 Windows 版本、DPI、输入法或物理桌面行为不能宣称通过。

## 交付

简要报告目标连接别名、是否成功登录、实际完成的操作、可见结果、仍受阻的步骤及
最终会话状态。只提供与验收有关且不含敏感信息的证据；无法观察的结果标为未核验。
