# 实施与验收

[返回总览](README.md)。以下为完整阶段计划；首批实现和实际退出条件记录见 [执行记录](EXECUTION.md)，不以部分接入代替整阶段验收。

## 1. 分阶段交付

阶段对应原设计的 P3–P5，但把可先获益的视口排版提前。每个阶段单独记录实际交付范围，未通过的快路径关闭并保留正确后端。

### 阶段 A：基线、块目录和依赖

依赖当前实现，不要求修改解析器。

- 固定源码基线、工具链、平台、release 配置和语料；保存工作区差异，避免只记录 HEAD。
- 从已提交语义快照建立 BlockId 目录、父容器、布局单元摘要和相邻间距归属。
- 用事务未改区间保留身份；拆分、合并、移动和全文回退的 ID 行为写入测试。
- 为源码复制、解析、投影、布局、绘制、资源准备和候选重复解析分别计时。
- 明确缓存键和失效矩阵，分开控件动作状态与占位尺寸。

退出条件：全文字节和语义范围不变，目录查询能和既有扫描结果对照，所有新数据为可丢弃派生物；测量能区分“没有重排”与“重排但没有绘制”。

### 阶段 B：视口文字精排

依赖阶段 A。保留全文解析和完整只读投影。

- 拆出块内布局，建立估计/实测高度目录及 f64 累计坐标。
- 短段落按块，代码按物理行组，表格按完整行生成几何；容器保留共同装饰与入口。
- 视口和预取优先，未知目标先排版再命中；迁移上下导航、选择、菜单、IME 几何和末尾添加区。
- B3 必须包含[屏外交互保留](DESIGN.md#611-屏外焦点与交互保留2026-11-15-补充待实现)：正文输入宿主持续挂载，焦点/IME 单元独立于可见区保留，按布局身份去重，不连接两个区域之间的全部单元。
- 实测高度批量替换，按源码锚点补偿滚动；处理主动滚动、文末钳制和远距离跳转。
- 保留完整布局作为测试对照，运行期不双算。长单段和长代码行使用明确的完整排版慢路径。

退出条件：结构呈现、映射与交互差分通过；固定视口、同类短块的文档扩大后，每次新建精排单元数随工作集而非全文块数增长。超长单块单列。此时可宣称“文字按视口精排”，不能宣称“普通输入已经局部解析”或“屏外资源已全部惰性化”。

#### B3 的具体接入顺序

1. 在 UI 调度层区分滚动来源：用户阅读、只读导航、编辑后显露光标和高度补偿。阅读滚动不触发 `ensure_caret`；实际输入与预编辑更新沿现有规则处理。
2. 建立交互保留描述与锚点解析；先覆盖普通段落，再接代码行组、表格整行、列表/引用及局部/全文源码。保持现有单一正文 FocusHandle，并让 `paint_frame` 每帧注册 InputHandler，包括无可见文字/全占位帧；不能只保留焦点句柄。
3. 将可见区、预取和保留单元合并成唯一布局集合；高度树中每个单元只累计一次，屏外单元不产生可见点击区域。宽度/主题/模式变更与事务映射共同校验当前身份。
4. 接入临时 IME 范围和两阶段导航：只读目标可先请求精排再滚动，活动输入/候选几何则必须在平台同步查询前就绪，不把返回 `None` 当作延期协议；新请求取代旧请求。点击切换必须先处理组合输入，不先释放旧保留。若屏外候选位置未通过平台验收，预编辑期间限制滚动至候选锚点仍可见，并记录限制。
5. 记录下表专项结果及工作量；复用完整布局后端进行差分，再做 macOS/Windows 真机验收。脚注尚未实现时用普通源码锚点测试导航，B3 不依赖脚注阶段 FN1–FN5。

额外放行条件：主动滚离后正文焦点和选区不变；输入准确落在原光标并按输入规则显露；跨屏候选确认/取消无丢字、重复换行或多余事务；远处焦点与视口距离增加时，不新增中间区段精排。平台暂时无法可靠定位候选时，保持安全回退并记录未放行平台，不宣称完成。

### 阶段 C：资源范围调度与缓存生命周期

依赖阶段 A/B 的范围查询，投影资源接口可分批迁移。

- 将预览资格目录、请求集合和缓存存活拆开，保持既有候选顺序、32 块资格及资源上限。
- 可见代码先普通样式，再识别与高亮；添加实际高亮工作量与预算，不能用识别预算替代。
- 图片/Mermaid 只调度符合模式、冻结和范围要求的候选，失败结果滚动后仍为终态。
- 公式将资源准备移到按需入口，可见行使用真实度量；PDF 继续按独立导出快照获取资源。
- 资源结果校验内容和服务身份，按新视口决定挂载；几何改变进入统一高度修正批次。

退出条件：屏外不发生新的非必要资源任务，滚回命中保留缓存，快速滚动/编辑不会接收过时结果；第 33 个候选行为与现有限额一致。所有已承诺资源类型都迁移后，才可宣称“高亮和资源渲染按视口调度”。

### 阶段 D：累计字节树与焦点覆盖

依赖阶段 A，可以在 B/C 完成后集成，不阻塞首轮排版收益。

- 建立覆盖所有原始字节的片段树和锚点目录，先逐键更新树路径。
- 接入 `PreparedEdit` 的多范围位置变化，处理嵌套、空块、EOF、拆分/移动和历史身份。
- 再增加单连续焦点覆盖，比较逐键树更新与失焦归并的分配、按键和失焦耗时。
- 保存不等失焦，结构变化和历史恢复可提前归并。后台查询只持有匹配源码的索引版本。

退出条件：随机事务下与朴素前缀扫描一致，焦点归并前后所有合法锚点和 offset 查询一致。若覆盖没有可测收益，保留直接树更新即可，不影响用户提出的统一 offset/BlockId 映射目标。

### 阶段 E：局部语义与分块投影

依赖阶段 D；可以先做独立正确性原型，正式迁移需通过放行条件。

- 提供候选语义后端与 `SemanticQuery` 门面，隔离全局 node/token 编号。
- 从已闭合代码正文开始，新增安全段落，再扩展列表/引用。暂不承诺所有结构命令局部化。
- 定义 `Local` / `FullRequired` 结果与回退原因，记录尝试范围、实际解析字节、边界扩展和最终路径。
- 共享未变语义分支、物理行、引用依赖、token 和字段来源；验证器继续检查同一候选。
- 接入分块投影和相对映射，迁移全文 grapheme/UTF-16 索引的更新路径，取消每键 flatten。
- 复用补全的相同候选解析，Undo/Redo 沿同一后端及验证契约。

退出条件：与全文后端逐次差分一致，普通输入快路径具有可测覆盖率，修改后没有隐蔽的完整 AST/展示索引重建。无法提供等价解析上下文时停止开放相应快路径，保留全文实现并记录阻塞点。

### 阶段 F：IME、持久化与跨平台收尾

保存和 IME 的正确性从阶段 B 就必须保持；本阶段交付临时投影的局部性能和完整验收。

- IME 使用带临时代次的局部覆盖与投影，确认一次提交，取消恢复，确认失败保留候选。
- 验证焦点内保存、后台保存旧快照、继续编辑、撤销回基线、关闭/打开流程。
- 验证原始字节、LF/CRLF/CR、嵌套前缀及保存目标绑定不变。
- 进行 macOS / Windows 真机滚动、输入法、缩放和资源到达交互验收。

退出条件：功能矩阵全部通过，达到对应平台的目标后才作性能结论。未通过的超长块场景明确保留限制，不以普通短段落结果替代。

## 2. 建议接口边界

这些是职责划分，不要求直接使用下列名字，也不新增生产反向依赖。

| 契约 | 输入 | 输出/保证 |
| --- | --- | --- |
| `BlockDirectory` | 同版语义、源码及事务影响 | 稳定 ID、容器和编辑目标；可查询完整范围 |
| `PositionIndexView` | 索引版本、可选焦点覆盖 | 当前版本 offset/锚点双向查询，拒绝身份不匹配 |
| `SemanticUpdate` | PreparedEdit、旧语义、上下文 | 完整有效候选或带原因的全文请求 |
| `ProjectionView` | 当前语义、显隐、模式和资源依赖 | 分块文本及双向映射，按需查询，不强制全文拼接 |
| `LayoutWindow` | 投影单元、布局参数、交互目标、视口 | 实测几何和高度更新批次，标识尚未测量区 |
| `InteractionRetention` | 当前文档锚点、选区活动端、IME 范围、导航请求 | UI 拥有的交互保留集合；同单元去重、事务后重定位、结束后释放，不拥有可编辑正文 |
| `ResourceDemand` | 资格目录、工作集、模式、服务代次 | 有界请求及独立缓存存活信息 |
| `FrameToken` | 文档/投影/预编辑/布局/视口与几何代次 | 命中、控件、候选框采用同一版本的证明 |

未知扩展没有声明局部依赖时继续完整路径。旧接口可保留用于迁移和测试对照，但应计数，避免热路径通过适配器偷偷重建全文。

## 3. 正确性测试矩阵

| 类别 | 必测用例 | 对照与通过条件 |
| --- | --- | --- |
| 字节索引 | 增长、缩短、等长替换、多 edit、EOF、空文档、连续空行 | 叶子拼接等于 Source；累计长度、双向查询与扫描一致 |
| 嵌套与归属 | 引用内列表/代码、列表内引用、空项、容器共起点 | 父子包含有效；前缀及分隔符只计一次 |
| 焦点覆盖 | A 变长后点击 B、负 delta、清空活动块、提前归并 | 归并前后查询和选区一致，不新增历史/dirty |
| 语义边界 | 围栏提前闭合、删除拼出标记、Setext、表格分隔线、HTML | 每次编辑后与全文解析的语义、token、字段和引用一致 |
| 引用依赖 | 重复定义、定义重排、未定义变已定义、屏外定义变化 | 所有使用点语义正确或明确全文回退 |
| 身份与历史 | 重复段落、拆分/合并、移动、删除后撤销 | 缓存不串块，历史验证失败保持源码和双栈 |
| Unicode | CJK、代理对、组合音符、ZWJ、区域指示符、超长结合串 | 合法边界及两种 affinity 与全文算法一致 |
| 换行 | LF、CRLF、CR 及混合换行；替换邻接换行 | 不拆 CRLF，保存未改字节一致 |
| 投影与显隐 | 标题点击、行内祖先、代码字面内容、表格空单元格、公式 | 小文档枚举光标位置，与现有投影对照 |
| 布局 | 短块、跨屏引用/列表、表格整行、长代码、窄窗和缩放 | 测量完成后可见字形、行高、命中与完整布局等价 |
| 高度补偿 | 上方增长/缩短、锚点自身折行、多个资源同批到达 | 非钳制且锚点存活时屏幕 Y 误差初定 ≤ 1 物理像素 |
| 滚动意图 | 快滚、反向、远跳、滚动条拖动、文末钳制 | 新用户意图不被旧任务覆盖；异常锚点另列原因 |
| 未测量命中 | 点击占位、跨屏拖选、上下键进入新块 | 先精排后命中，不能返回估计文本位置 |
| 屏外焦点 | 光标在首段滚到末尾/反向、拖滚动条、再输入/导航 | 不因阅读滚动失焦或弹回；输入落在原源码位置；没有中间区段全量挂载 |
| 保留粒度 | 表格单元格、长代码、跨屏引用/列表、选区活动端、局部/全文源码 | 按安全单元保留；高度不重复、容器不整体常驻；跨屏复制仍来自完整源码 |
| 保留生命周期 | 前方编辑、活动块删除、Undo/Redo、主题/缩放/宽度变化、切换文档 | 新锚点与当前帧一致；旧任务/旧 BlockId 不恢复过时几何；焦点转移后旧保留释放 |
| 屏外 IME | 组合输入时滚动、候选框查询、确认/取消、窗口失焦再聚焦 | 当前临时范围真实几何；无卸载导致的确认/取消；Enter 不重复执行结构命令 |
| 输入宿主存活 | 首屏全占位、滚到纯空白、资源块占满视口、当前无可见文字 | 当前帧仍注册输入处理器；平台不因缺失矩形落到原点或保留旧位置；不以 FocusHandle 存活替代输入注册验证 |
| 导航往返 | 远处目标未测量、连续跳转、返回前编辑/删除目标 | 当前请求才可滚动；锚点安全映射；脚注接入后增加 FN3/FN5 专项 |
| 资源 | 超过 32 候选、滚出滚回、失败重现、旧结果、文档切换 | 保持资格和限额、无重复无限重试、无过时挂载 |
| 指纹 | 相同 CRC/不同字节、同内容不同上下文 | 拒绝错误复用，未改片段不重复扫描 |
| IME | 预编辑跨块、候选确认 Enter、取消、失焦、资源到达 | 临时源码不进历史；候选框使用当前实测几何 |
| 保存/导出 | 焦点未失去时保存、保存旧版后继续编辑、屏外导出 | 文件对应请求快照；dirty 正确；导出内容不随视口裁剪 |

随机差分必须记录 seed、原文和操作序列，并保留可复现的最小失败样例。差分比较语义和范围，不要求两个独立解析器实例分配相同内部 ID。归一化只允许屏蔽无意义身份，不能屏蔽源码范围、样式或丢失内容。

## 4. 性能测量

沿用 [既有拟定目标](../../31_Large_File_Optimization_Design.md#21-拟定性能目标)，这些数值是目标，不是本次成果。热滚动 P95 ≤ 16 ms / P99 ≤ 33 ms，普通输入 P95 ≤ 100 ms / P99 ≤ 200 ms，IME P95 ≤ 50 ms，典型文档打开至可交互首屏 P95 ≤ 3 s。按阶段和平台分别判定，P3 不承担尚未实现的 P4/P5 输入目标。

语料采用 1、5、10 MiB，记录实际字节、物理行、语义块、布局单元、最大单块和最大深度。覆盖普通短段落、结构密集文档、很多小围栏、单个长代码块、单个长代码行、大表格、嵌套列表/引用、10 MiB 单段、公式/图片/图表混合，以及三种换行。

每次记录：

- 源码复制、候选准备、验证器、语义、投影、平台索引、精排、绘制提交耗时。
- 输入到可见、首屏、失焦、远跳、冷滚动、热滚动、缩放与保存的 P50/P95/P99。
- 实际解析字节/节点、局部覆盖率、扩大范围次数、回退原因及全文路径延迟。
- 新建精排单元/行/字形数、缓存命中、估计误差、锚点偏移、占位缺口持续时间。
- 可见/预取/交互保留单元数与字节、去重后总量、几何缺失及慢路径次数；相同视口和焦点块大小下，逐步增加两者间距离的精排工作量与峰值内存。
- 高亮实际处理字节/块、语言识别次数、预览任务/缓存数、取消及丢弃旧结果次数。
- RSS、各缓存保留字节、活动快照数、历史与在途任务占用及峰值。

固定视口的扩展性测试应保持块大小和结构分布相同，扩大总块数后检查新增精排工作集没有线性增长。打开建目录和第一版结构重建仍可线性，必须从滚动/精排指标中分别列出。

同机同配置重复测量，禁用不相关并发负载。P95 至少 100 个稳态样本，P99 至少 1000 个，保留多轮完整分布和超时样本；样本数本身不代表置信保证。网络资源首次加载与已缓存绘制分开，不能把网络等待混成纯排版收益。

## 5. 预算与故障回退

先沿用 [既有缓存预算设计](../../31_Large_File_Optimization_Design.md#10-内存缓存与回退) 的新增性能缓存 128 MiB 作为测量起点，不是整体 RSS 上限。源码、历史、保存快照以及原有服务缓存单列；必需语义索引和当前交互工作集不能因超预算而被删除造成错误命中。

每类任务使用有界队列，最新请求替换未开始的过时预取；用户编辑事务不按资源任务规则丢弃。限制旧快照同时存活数量，监控快速编辑、导出、保存并发时峰值。同步操作的最大耗时不能只靠队列长度推断。

内部 rollout 开关按位置索引、虚拟布局、范围资源、局部语义和 IME 分开。关闭某个优化恢复同版正确路径，不改变文件、撤销记录或保存格式。测试可以双算，生产默认不双算。任何真实事件回调中的检查失败都报告并正常返回，不能让 panic 穿过 AppKit。
