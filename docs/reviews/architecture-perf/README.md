# 架构重构性能采样

2026-10-13，同一台 Intel macOS 15.8.1 开发机器，Rust/Cargo/Clippy 1.99，`dev` 未优化构建。数据用于定位开销与比较局部改动，不设置应用延迟预算。

## 方法

重构前将 Rust 源文件与锁文件复制到独立临时目录，使用原 Document、presentation、渲染实现编译基线。来源校验和见 `baseline-source.json`；基线保留 88 项原单元回归，真实窗口 124 阶段通过。临时 GUI 基线只增加与当前版相同的计时作用域，不修改编辑算法。

无窗口测试共用 `examples/perf_support/mod.rs`：1624 字节，8 次重复混合语料，包含标题、中文、emoji、组合字符、粗体、代码、链接、嵌套列表、管道表格、Rust 围栏及公式。每项预热 8 次，采样 96 次，按排序索引取得 p50/p95/p99。输入项同时计入插入和撤销，选区项计入往返两次移动；不能解释为单次按键总延迟。公式、高亮缓存预热。

GUI 使用相同 smoke 场景和窗口变化，在 refresh、prepaint 排版与 paint 回调作用域采集耗时，包含对应函数同步执行的工作。帧数随系统调度变化；聚合分位数不能逐帧配对。Mermaid 服务对照固定 `flowchart LR / A[中文] --> B[保存]`，不包含后台排队等待。宿主缓存项测量当前 AST 查询、绑定和缓存命中，不包含实际渲染。

原始机器可读结果保留在本目录。桌面调度、编译和测试任务会引入噪声；未隔离 CPU、未做多轮统计显著性分析，尤其不能把 p99 波动描述为全面改善。解析器、GPUI shaping、Formulary 和 Merman 算法均未替换。

- 该图缓存 1 项、像素 280000 字节。生产缓存仍限制 32 项、32 MiB；资源生命周期和代次失效通过契约测试验证。

## 重复采样

```sh
cargo run --locked --example architecture-perf
cargo run --locked --example architecture-perf -- services
RYNE_PROFILE=1 cargo run --locked -- --smoke-test > /tmp/ryne-profile.log 2>&1
python3 scripts/summarize-profile.py /tmp/ryne-profile.log
```

对照旧版时，在迁移前源码快照中使用相同语料、采样次数和作用域计时。当前仓库仅保留现行实现，不将两份可写编辑实现一起发布。测试依赖当前稳定 Rust，不用旧 Clippy 组件替代当前编译器。

大文档、超长段落、长队列排队等待与进程峰值内存尚未形成系统对照；这些数据不能代替后续专项性能验收。
