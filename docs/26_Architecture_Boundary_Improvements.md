# 架构边界改进

日期：2026-10-14。范围为本轮架构审查确认的五项改进。继续在当前分支开发，
保留已有两个未跟踪 SVG；不修改外部依赖版本、Cargo.lock 或全局工具配置。

## 实现

### 列表控件与语义查询

`ryne-features/src/list_actions.rs` 的控件批次共享 `Extents`，物理行与代码范围只提取一次。
条目首末行通过二分定位，不再逐条遍历全文行；各列表的首末同级标记一次汇总。
任务按钮和条目菜单复用相同的完整条目范围。结构命令继续使用同一范围计算规则。

`ryne-syntax/src/list.rs` 一次索引列表子节点序号与任务标记，物理行使用二分定位。
保留原始编号、嵌套关系、容器前缀、尾部分隔空行及任务状态语义。
本轮没有引入跨快照语义缓存或增量解析；全文解析仍是保留限制。

### IME 的所有权与事务

会话私有持有 `Composition`，提供只读访问和 `update_composition`、`commit_composition`、
`commit_composition_text`、`cancel_composition` 接口。可编辑临时文字、选区、光标及
`projection_state` 的解析和范围映射也由会话生成。

UI 保留平台 UTF-16 范围转换、输入回调及窗口几何。无效的替换范围拒绝执行；
平台选区若切入代理对，保留有效预编辑并将候选内选区回退到正文末尾。
更新先验证完整候选，确认通过原命令规划与验证链一次发布源码、选区和历史，然后才清除预编辑。
规划或验证失败保留原文档、预编辑和历史；UI 的后续导航、编辑、保存、导出与关闭动作停止。
普通源码提交不能穿过活动预编辑，会话撤销也要求先确认或取消预编辑。

平台确认范围不等于 marked range 时，仅替换确认范围与预编辑的并集，保留外侧源码字节；
确认的最终选区与内容在同一次会话提交中校验。临时投影映射已覆盖替换末端的后续块边界，
避免将后续块起点错误映射到预编辑开头。取消不创建文档事务。

### 通用编辑意图

`EditIntent::Delete`、`LineBreak`、`Tab` 按同一编辑槽位执行功能处理器。
内置优先级为表格 300、代码 200、列表 100、段落/普通文本 -100；显式注册顺序约束仍按既有协议生效。
未命中返回 `None`，不发布中间选区或增加历史；只有最终计划通过会话验证并发布。
额外静态处理器可以拦截这些意图，无需修改 UI 的按键回调。

换行规则分别归属表格、代码、列表和段落模块。UI 不再依次调用表格、代码、列表、段落的删除或 Tab 命令。
普通删除通过投影的 grapheme 范围映射排除两侧隐藏标记，使用同一源码事务；纯源码引擎也支持通用删除与 Tab。
折叠图表边界的点击/方向导航和删除前进入源码，仍依赖本帧原子图表几何，由 UI 处理。
旧的专用会话命令保留供已有测试和内部调用使用；没有增加引用结构编辑等新产品功能。

### 块身份与呈现元数据

`ryne-syntax::block::Block` 只持有 `BlockKind`、范围和锚点，不再持有图标、标签或中文名称。
`BlockKind` 包含标题级别、列表的有序/任务属性等语义；列表定位据此判断。
`ryne-extensions::BlockMetadata` 映射默认图标和回退文字；UI 按语义类型选择七种语言的文字。
自定义元数据可不提供内置类型并使用回退名称。更换图标不再改变语义判断或本地化键。

### 投影与高亮失败边界

会话和导出使用 extensions 的 `project_checked`。主呈现提供者的 panic 被捕获，
输出经 projection 的验证器检查：源码长度、UTF-8 边界、单调且完整的显示映射、
等长映射的内部字符边界、结构范围、表格形状、公式度量及图表像素尺寸。
无效或失败的主投影回退为可编辑原文；CR/CRLF 在显示中使用 LF，但源码范围仍指向原始字节。
纯源码引擎原有的字面显示约定保持不变。

高亮的 begin/spans/end 分别捕获失败，返回范围必须是当前代码块内的有效 UTF-8 范围。
失败保留结构化代码和普通文字样式；诊断进入 UI 原有去重、最多 64 条的记录通路。
内置呈现构造器也在应用高亮前检查切片范围。
该保护针对主投影与高亮，不是第三方插件安全沙箱，也不承诺硬中断渲染器或无限大小输入。

## 验证

- `python3 scripts/check-architecture.py`：9 个私有包与生产依赖方向通过。
- `cargo test --locked --quiet`：196 项单元测试通过，文档测试无失败。
- `cargo test --locked -p ryne-session --example render-interactions --quiet`：20 项历史原型回归通过。
- `cargo fmt --all --check`、`git diff --check` 与
  `cargo clippy --locked --workspace --all-targets -- -D warnings` 通过；
  fmt/clippy 使用 `/usr/local/bin` 中与当前 Rust 配套的工具。
- `cargo run --locked -- --smoke-test`：真实窗口完成 stage 0–247，退出码 0。
- `cargo run --locked -- --smoke-test-failure`：按预期报告失败并以退出码 1 结束，
  没有让 panic 穿过原生事件循环。
- `sh scripts/bundle-macos.sh debug`：生成 `target/Ryne.app`；
  `codesign --verify --deep --strict` 和 `plutil -lint` 验证通过。

新增回归覆盖确认失败保留预编辑并可重试、预编辑替换范围与 Unicode/三种物理换行、
临时投影不修改源码、通用按键的规则委托与优先覆盖、grapheme 删除及一次撤销、
主投影 panic/非法映射回退、高亮生命周期故障隔离，以及 1000 项任务列表的控件和原子切换。
原有结构命令、容器前缀、保存与源码字节回归全部保留。

窗口冒烟新增拒绝 IME 确认时保留候选、阻止关闭、保持几何和通用删除的检查。
真实窗口几何回调检查不能替代人工鼠标键盘及每种输入法候选窗口验收；不终止用户已有窗口。
