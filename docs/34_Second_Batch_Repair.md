# 第二批修复方案与验证记录

范围：R3 鼠标几何查询、R4 grapheme 导航、R5 删除规划、R6 混合表格，以及此前第二批执行说明中的 R9 PDF 遍历、R10 dirty 查询。
保持第一批修复、已有工作区修改、依赖锁定和统一源码事务；不实施增量解析、块级虚拟排版或贡献者缓存声明。

## 方案与验收条件

### R3：当前排版拥有命中目录

- 悬停先按现有代码面板 Y 索引查候选，首末行由 FrameIndex 获取；普通行按视口索引查询。
- TextLayout 构建单元格到视觉行目录，以及普通视觉行的 Y 区间和最近边界目录。
  单元格以实际几何和原行顺序标识，保留空单元格、折行、内边距、重叠行带和等距优先级。
- 最近行查询不能对表格所有列的 rows.top 直接二分；保留文档首尾、间隙及 affinity 的现有规则。
- 旧线性算法仅作为测试 oracle；窗口回归比较实际命中结果并记录候选访问量。
  索引随 TextLayout 失效，不允许旧几何解释新源码、IME 或宽度。

### R4：复用完整展示字符串的 grapheme 位图

- IndexedDisplay 提供严格前/后一个边界查询，方向键和删除共享实现；保持 EOF 和非法中间字节的定义。
- 保留公式/图表进入、隐藏前缀和上下游 affinity，不能降为逐字符移动。
- 对照完整 Unicode 分段，覆盖跨 span 结合符、ZWJ、区域指示符、长组合序列及空文档；窗口测试文末导航和扩展选择。

### R5：命令内共享惰性只读投影

- 同一次注册命令分发共享规划映射缓存，键包含源码身份、显隐/模式和公式服务代次；每次分发重新开始。
  规划器变化后的源码和视图必须得到新键。该缓存不接受 UI 几何，也不延伸到下一次命令。
- 列表、代码和段落处理器先查询当前位置相关的结构，再请求映射；无列表时不能构建列表边界用投影。
- 普通删除最多生成一份规划投影，多处理器委托不得重复生成；同一选区替换仍走源码事务。
- 回归覆盖代码字面内容、列表/引用前缀、空表格、跨块选区、三种换行、撤销、源码模式及扩展兼容。

### R6：快照持有表格/单元格归属查询

- syntax 层为有效表格和单元格建立有序范围目录，使用二分查找正文位置的归属；投影与 active_window 共用。
- 保留无效/列数不齐表格的原文回退、空单元格、转义管道、字面代码与容器/裸 CR 语义视图。
- 与线性查询对照；复测相同 256/512/1024/2048 表格语料，另测普通段落与行内代码交错，避免只验证单一语法。

### R9：打印布局按范围顺序消费样式和公式

- 每次 wrap 二分定位起点，随后单调推进样式与公式游标；文档级结构查询复用已有目录。
- 两个 PDF 编码器继续共用打印布局，不改变字号、断行算法、字形回退、分页或源码快照。
- 用旧查询 oracle 验证选择的样式/公式及打印场景一致，继续运行两编码器的长文档/公式/表格回归。

### R10：精确 dirty 在内容生命周期内更新

- core 在发布、历史发布和保存回执时计算并缓存 dirty；dirty() 为常量时间。
- 相同保存快照身份可快速判定干净，其余情况保留精确内容比较，不能用 revision 代替内容相等。
- 窗口标题只在实际标题变化时更新；覆盖等长替换、重输入原文、撤销/重做、旧保存回执、外国文档和失败事务。

## 执行结果

### 已实施

| 问题 | 实现 | 主要保护 |
| --- | --- | --- |

| R5 | 注册命令分发中共享 CommandDisplayCache；列表/代码/段落先二分查询相关范围 | 每次分发清空；只缓存只读映射，不保存 UI 几何；显隐、源码身份、模式及公式代次参与键 |

| R10 | 在发布、撤销/重做及保存回执时计算精确 dirty；查询只读取布尔值；原生标题仅在文本变化时更新 | 同身份快速判断，其余精确比较字节；重输入原文可变干净，旧保存回执绑定实际保存快照 |

### 回归覆盖

正式测试从第一批的 266 项增至 273 项。新增检查覆盖三种换行、等长修改/重输入原文/旧保存回执、
完整 Unicode 分段、嵌套表格逐字节归属、单命令仅一份删除规划投影、跨分发失效、代码字面内容、跨块删除与撤销。
打印测试对照原线性查询，逐页比较包含公式、中文、结合符和 Tab 的 SVG 场景，并以独立子范围模拟单元格 wrap；
两种 PDF 编码器已有的表格、公式及长文档回归也通过。

几何单元测试对包含 10,005 行的合成布局比较旧查询，覆盖列的 Y 重叠、空白/内边距、等距边界和文末。
真实窗口专项使用含 80 个代码块、80 个折行表格及 160 个公式的文档，对采样位置比较新旧命中与公式点击，
包括超宽公式越过单元格边缘；实际为 1,841 个视觉行，最多检查 3 个候选。
这里的候选数不包含二分查找步骤，不能等同于整个鼠标事件的常数成本。
窗口检查还覆盖滚动后布局共享、代码块之后的末尾悬停、5,000 个 Unicode 段落后的左右/扩展选择、
组合字符删除、标题 dirty 状态、撤销和 IME 几何；源码与预编辑变更均拒绝旧帧。

### 保留限制

- 内容修改、撤销和 IME 仍全文解析/投影，正文仍全文精排；本轮未交付 P3–P5。
- 新索引增加与视觉行/结构数量成比例的内存；没有测量峰值 RSS，也未做 release 端到端 P95 测量。
- dirty 的精确内容比较移至内容/保存生命周期；等长编辑时仍可能比较全文，不宣称编辑整体为常数时间。
- 命令规划缓存仅覆盖单次分发；贡献者稳定代次声明与跨命令缓存不在本轮范围内。
- 候选目录减少几何扫描，原子语义入口及一次事件中其他工作仍有进一步优化空间。
- 验证平台为 macOS；Windows 桌面与各实际中文输入法候选窗口仍需实机验收。
