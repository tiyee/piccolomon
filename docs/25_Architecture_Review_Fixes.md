# 架构审查修复记录

日期：2026-10-14。范围为本次代码审查确认的六项问题，基于当前工作区已有功能继续修复，
不重置已有修改，不变更依赖锁定。Markdown 源码仍是唯一真相，所有内容修改通过会话事务提交。

## 修复与实现边界

| 问题 | 修复 | 主要实现 |
| --- | --- | --- |
| 超时图表被丢弃，下次刷新再次排队，后续图表可能饥饿 | 当前有效任务的截止失败进入错误缓存；过期或取消结果仍丢弃。内容或服务代次变化后可重新尝试 | `crates/ryne-session/src/jobs.rs` |
| 每个源码字符扫描全表单元格与插入项 | 表格边界、空单元格锚点及插入项排序后按源码位置顺序消费；图表和公式范围采用有序游标 | `crates/ryne-features/src/presentation.rs` |
| 公式缓存满 256 项时全部清空，257 个公式持续失配 | 逐项淘汰最久未使用项，强引用最多 256 项且 SVG、源码键和路径字节最多 16 MiB；最多 4096 个弱引用键复用活跃视图持有的公式 | `crates/ryne-services/src/math/cache.rs` |
| 闪烁重复塑形、折行，单行遍历全文样式 | 抽出不可变正文布局；用二分定位相关样式和公式区间；每帧重算光标、选区及菜单覆盖层 | `crates/ryne-ui/src/text_layout.rs`、`layout_frame.rs` |
| 注册表仅声明元数据，实际命令仍由中央分支调度 | 注册并执行类型化 `CommandHandler`、输入处理器和 `PresentationProvider`；内置命令拆为功能处理器，额外静态功能可经 `with_feature` 接入 | `crates/ryne-extensions/src/execution.rs`、`registry.rs`；`crates/ryne-features/src/commands/dispatch.rs` |
| 一个渲染控件提供者失败使所有控件消失 | 按提供者收集、验证和隔离批次，非法批次整体舍弃，保留其他提供者及诊断；执行仅重新验证目标提供者 | `crates/ryne-extensions/src/render_actions.rs` |

命令处理器按依赖和槽位排序执行：返回 `None` 委托下一项，首个计划获接受，错误或 panic
终止当前规划，最终仍由会话验证和提交。提供者不能直接取得可变文档。主文档呈现为独占贡献，
不是多个任意布局提供者的自动合成。新增同类命令无需改中央 `EditIntent` 分发，但新增意图类型、
呈现原语或 Widget 仍需扩展对应模型；本次没有交付动态加载或公开插件 SDK。

正文布局缓存键包含源码快照、投影代次、内容栏、源码模式、字体、显示缩放及控件预留空间。
滚动和光标闪烁复用相对正文几何；影响折行的输入或显示变化会失效。控件动作及命令数据从当前帧
重新绑定，不因几何复用而沿用旧目标。旧几何不能处理新源码或预编辑。排版与显隐不产生 dirty 或历史。

图表截止检查仍位于 Merman 处理阶段之间，不能硬中断布局内部。错误缓存防止的是重复调度，
并未改变该执行限制。渲染控件诊断按内容去重，会话最多保留 64 条；隔离 Rust panic 不构成进程安全沙箱。

公式缓存预算只约束缓存保留的资源字节，活跃视图持有的资源和弱引用键元数据不计入这项预算。
弱引用不会延长资源寿命，也不是无限容量缓存。内容编辑仍全文解析，首次布局仍处理整份文档；
这些改动不意味着完成所有大文档优化。

## 性能采样

复现命令：

```sh
cargo run --locked --example architecture-perf -- scaling
```

本机 Debug 构建，固定语料，各项预热 8 次、采样 96 次。表格投影耗时包含功能层投影，
不包含整次 GUI 输入延迟；公式测量为已持有上一投影资源时的完整投影。

| 项目 | P50 / ms | P95 / ms | P99 / ms |
| --- | ---: | ---: | ---: |
| 100 行表格 / 1439 字节 | 2.4715 | 2.8018 | 2.9945 |
| 200 行表格 / 2839 字节 | 5.1522 | 6.1266 | 7.2089 |
| 400 行表格 / 5639 字节 | 10.6844 | 11.4128 | 14.2535 |
| 800 行表格 / 11239 字节 | 27.3087 | 39.8128 | 251.0672 |
| 257 个公式的热投影 | 5.3528 | 5.9459 | 6.3658 |

257 个公式全部复用原资源。原审查探针相同表格语料的三次采样均值为
21.419 / 71.813 / 252.201 / 935.261 ms；采样统计口径不同，不据此宣称精确加速倍数。
本轮运行期间还有窗口检查，800 行样本的高尾延迟保留如实记录，不能作为稳定延迟保证。
该基准用于定位回归，不代替 Release 构建、超长段落和完整大文档验收。
