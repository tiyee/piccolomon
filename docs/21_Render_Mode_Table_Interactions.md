# 表格渲染模式交互实施记录

日期：2026-10-13。设计基线：[20 · 渲染模式交互扩展](20_Render_Mode_Interaction_Extensibility.md)。

## 产品行为

结构化表格的每个 cell 在 hover、正文焦点或完整选区位于自身内部时显示右侧竖向三点按钮。
使用现有 `assets/icons/more_vertical.svg`；添加、移动、删除和选中标识也使用现有 SVG。
点击打开菜单，hover 只显示入口。点击不会先移动正文光标或改变选区。

| 菜单组 | 操作 |
|---|---|
| 对齐方式子菜单 | 靠左、居中、右边；显示当前列状态，修改 Markdown 列对齐 |
| 插入 | 添加行、在上面添加行、添加列、在前面添加列 |
| 移动 | 上移一行、下移一行、向左移动列、向右移动列 |
| 删除 | 删除行、删除列 |

保留表头：不允许删除或移动表头，不允许在表头之前创建正文行。第一个正文行不能上移到表头；
末行不能下移，首末列不能越界移动，最后一列不能删除。不可用项显示灰色。
表头上的“添加行”在 Markdown 分隔行之后插入正文行。

Alt+Enter 打开聚焦 cell 的菜单；方向键在菜单与子菜单中导航，Enter 激活，Escape 先关闭
子菜单再关闭菜单。点击外部、滚动、失焦、编辑或源码切换关闭菜单。
macOS 操作快捷键与参考图一致：Ctrl+Cmd+方向键插入，Option+Cmd+方向键移动，
Ctrl+Cmd+Backspace 删除行，Ctrl+Shift+Cmd+Backspace 删除列。其他平台采用 Ctrl 作为主修饰键，
移动额外使用 Alt；菜单显示对应提示。未进行 Windows 桌面交互验收。

控件的 24 px 空间在文字 shaping 前预留，按钮显隐不改变折行。IME 临时投影也计算相同的
控件空间，但不生成可激活入口。全文/对应局部源码、拖选和预编辑期间隐藏操作。

## 扩展通路

- `extensions/render_actions.rs`：`RenderTarget`、菜单项/分组/子菜单/快捷键元数据、
  只读 `RenderActionProvider` 和可执行 `RenderActionRegistry`。
- `features/table_actions.rs`：声明 13 个表格命令、每个 cell 的贡献、当前对齐与边界可用性。
  `MarkdownFeatures::with_render_action_provider` 可以装配额外提供者。
- `features/commands/table_actions.rs`：只读解析目标并准备结构编辑；复用既有 Planner 的
  统一候选构建、选区/显隐/补全检查点变换。没有另外维护可编辑表格数据。
- `session`：收集贡献、拒绝预编辑/源码模式下的操作、捕获规划失败、重新验证目标及可用性，
  通过原有 `publish_plan` 原子提交、验证并维护撤销。
- `ui/render_controls.rs`：通用区域、SVG 入口、菜单组合、键盘与快捷键、帧令牌和事件消费。
  不根据表格命令 ID 执行业务算法。`i18n.rs` 维护七种语言消息及未知消息的 fallback。
- `ui/layout_frame.rs`：现有表格布局绑定源范围与声明式贡献，发布 cell 区域和按钮预留空间。
  不在布局中定义具体菜单项或源码修改算法。

命令注册检查提供者、命令命名空间与重复 ID；贡献验证文档身份、范围、预留宽度及命令引用。
点击和执行时检查文档、投影/布局代次、视口尺寸、实际滚动及输入状态。
旧修订或旧布局不能操作当前源码。菜单操作始终使用点击 cell 的语义目标，光标可在表格外。

同一 source 区域的多个贡献合并到一个入口；目前支持分组菜单和一层子菜单。
新增同类命令只增加提供者贡献及规划，不需要 UI 或会话的业务分支。
新增其他布局形态仍需发布对应区域；任意 Widget、参数 schema、第三方翻译注册、
运行时卸载、指针捕获与插件隔离尚未实现。当前实现仍全文生成贡献，并非大文档性能优化。

## 源码和历史

操作保留外层引用/列表上下文、未修改字段字节、转义管道符、代码字面内容及 LF/CRLF/CR。
行移动保持原位置的换行约定，包括文末缺少换行；列移动同步移动表头、分隔行与正文列。
无外侧管道符时，如空边缘单元格需要，补上必要外侧管道符以避免丢失列。
不完整或当前语义适配器无法确认的表格保留原文，不提供结构菜单。

每次内容修改只有一次候选事务及撤销；相同的显式对齐选择不增加历史。
焦点在目标 cell 时，结构操作后重新定位到对应单元格或新插入单元格，保持 grapheme 边界。
表格外选区按源码事务映射保留；纯贡献、hover 和打开菜单不 dirty。
提交后再次确认表格结构，失败的候选不发布；现有验证器拒绝时源码、选区和历史均不改变。

## 验证

新增 12 项真实会话回归，覆盖全部操作、三种换行、缺少文末换行、容器上下文、空单元格、
可选外侧管道符、转义管道符、Unicode/grapheme、焦点跟随、检查点、一次撤销/重做、
禁用边界、旧身份、源码/IME 状态、验证器失败及额外自定义角色提供者。
新增菜单 SVG 嵌入与非空栅格验证，保留七语言完整性测试。

真实窗口冒烟扩展到 151 阶段：原有回归保留，新增 cell 区域与文字预留宽度、hover/focus、
点击菜单不改变选区、分组与子菜单、键盘激活、操作快捷键、行列编辑、撤销、旧帧拒绝、
源码模式、预编辑区域与隐藏、拖选隐藏。所有检查失败正常返回非零，不通过 AppKit panic。
这属于真实几何的回调检查，不代替全部人工鼠标、键盘或各输入法候选窗验收。
