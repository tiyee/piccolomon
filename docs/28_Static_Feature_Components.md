# 静态功能组件与适配器

保持九个私有包和现有依赖版本。唯一可提交文档仍属于 core/session；本次不增加动态库加载、脚本运行时、第二份富文本或任意 Widget 协议。

## 统一装配

`FeatureModule` 使用一个 `Registrar` 提交命令/输入规则、主文档呈现、渲染控件、预览、块菜单和模板。`BuiltinFeature` 是兼容名称。构建过程先暂存全部贡献，再校验依赖顺序、贡献 ID、排他槽位及控件命令命名空间，全部成功才发布 `Registry`。

代码、列表、表格模块将命令和控件放在同一次注册；块菜单和模板模块也提供实际实现。`MarkdownFeatures` 统一从注册器查询，不再另建控件注册表或直接返回固定菜单/模板。`FencedPreview` 实现预览端口，在自己的注册过程中接入执行路径。旧 `with_render_action_provider` 通过 `ControlAdapter` 参与同一注册过程。

新增现有原语可表达的静态功能：实现 `FeatureModule`，在 `register` 中提供所需能力，再用 `with_feature` 在装配处接入。无须修改会话或 UI 的命令业务分支。既有通用命令枚举、`InsertBlock` 与 `BlockKind` 仍是静态语义集合；增加新的语法或呈现原语仍需要明确扩展协议。旧描述性槽位不自动成为可执行插件接口。

## 呈现组件

`presentation/code.rs`、`list.rs`、`quote.rs`、`table.rs` 负责各自的语义选择、结构显隐、样式和表格文字替换。组件输出源码相对的 `BlockContribution`，不拥有最终 `Display` 或可编辑文档。

统一组合器保持原有次序：代码与图表、表格/列表结构、标题与行内显隐、列表/引用前缀再保护、表格替换、公式及源码模式。每份范围贡献先完整验证 UTF-8 范围，再应用掩码与样式；失败回退可编辑原文。资源替换和最终映射仍统一生成，并沿用宿主投影校验。

这四种块组件是主文档呈现内部的静态组合，并未提供任意第三方块呈现 ABI。避免让多个提供者分别重写最终映射。

## UI 状态组件

`interaction_state.rs` 定义 `MenuState`、`CaretController`、`FileOperationState`、`ViewportState`。所有事件、排版、绘制与真实窗口检查迁移到同一组状态字段，没有镜像状态。

菜单统一关闭、光标闪烁重置、文件替换阻塞判断、几何失效入口由对应组件承担。GPUI 生命周期与异步调度仍在 UI；平台输入适配器继续调用 session 的 IME 和事务接口。

## 导出与语义查询

导出描述增加标签键与回退文案；原生菜单和窗口内菜单都遍历注册描述，通过 `ExportRegistered { id }` 分发。同一动作类型可以服务新增 PDF 后端。默认 PDF 快捷键保留。增加后端仅需实现 exporter、注册描述，新增专属译文可在语言目录补充。共享分页和原子字节写入继续使用上一轮适配器。

`ryne-syntax::SemanticQuery` 提供块、代码、表格、列表、容器插入上下文及带来源身份的源码读取。呈现、预览调度及相邻插入已开始使用门面。保留现有解析器快照类型，不复制 AST、不增加解析器运行时替换层。

## 验证重点

- 一个测试功能模块同时提供控件、模板、预览和块菜单；校验查询实际执行及失败构建不影响已有注册表。
- 组件中的无效 UTF-8 范围在应用任何修改前拒绝。
- 语义门面在 LF/CRLF/CR 与嵌套容器下保留源码，并拒绝其他文档身份和越界范围。
- 自定义导出描述无需新增 UI 动作类型即可出现在菜单，七种语言的既有入口保持译文与后端 ID。
- 沿用既有嵌套块、代码字面内容、表格映射、撤销、IME、导出快照及真实窗口回归。
