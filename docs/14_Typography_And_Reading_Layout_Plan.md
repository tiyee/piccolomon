# Ryne 字体与阅读排版调整方案

日期：2026-10-12。状态：字体、阅读栏与语义间距已落地；实现和验证范围见文末。本文同时保留调整前的检查依据与设计目标。

## 1. 目标与现状

默认外观采用安静、清晰的文档排版：中文正文舒展，英文与数字协调，标题有层次，代码容易辨认，宽窗口下保持适合阅读的行长。

调整前检查依据 `src/editor.rs`：

- 正文、标题和界面请求 `.SystemUIFont`，代码请求 Menlo；尚未明确正文的中英文字体搭配。请求字体名称不等于已经核实所有字符最终使用的字体。
- 正文为 18 px / 29 px；H1–H6 为 34/48、29/42、25/37、22/34、20/31、18/29，标题统一调用粗体。
- 代码块为 16 px / 25 px；行内代码仍沿用所在行字号。表格正文为 18 px / 29 px。
- 内容左侧固定 64 px、右侧 28 px，没有阅读栏最大宽度；窗口变宽会持续增加行长。
- 常规文本逐显示行累加高度，段落和标题间距主要由源码空行决定；代码与表格另有局部间距常量。
- 字体、颜色和几何常量分散于排版、绘制及命中计算。普通文本路径直接采用固定行高，公式混排路径已经考虑实际 ascent/descent。

当前观感的判断来自代码分析，尚未进行当前运行窗口的视觉验收。系统字体本身并非缺陷；行长、字重和空间节奏是同样重要的调整对象。

## 2. 字体选择

| 用途 | 首选与回退策略 | 理由 |
|---|---|---|
| 正文、标题、列表和表格 | Helvetica Neue 为主字体，缺字优先 PingFang SC，其他文字及 emoji 沿用平台回退 | 明确拉丁文字与简体中文的搭配，统一文档气质 |
| 工具栏、菜单、状态栏 | `.SystemUIFont` | 保持原生界面的紧凑度与系统习惯 |
| 行内代码、代码块、源码 | Menlo，中文缺字使用 PingFang SC，其他缺字使用平台回退 | 代码使用等宽拉丁字形；不假定中文回退也与拉丁字符等宽 |
| 数学公式 | Formulary + 内嵌 STIX Two Math | 保留数学符号与公式基线的正确性；缺字或不支持的变体保留源码 |
| Mermaid | 保留现有渲染字体，外部留白及配色与正文协调 | Mermaid 自有布局和缓存，不随正文换字体强行替换图内字形 |

Apple 的 [macOS Tahoe 字体列表](https://support.apple.com/en-ie/122869)列出了 Helvetica Neue、PingFang SC 和 Menlo。列表不代替目标机器的实际可用性检查；实现时检查 GPUI 0.2.2 的字体加载与缺字回退行为。首选字体不存在时选择可用的系统字体，不阻塞编辑，也不自动下载字体。

不手动按“中文/英文”切字符串分别测量；让同一次 shaping 处理回退、标点、组合字符与 emoji。保留 Markdown 的粗体和斜体语义，不为追求整齐改写字符、插入中英空格或人为加字距。

## 3. 字号与字重

下表中的 px 为 GPUI 逻辑像素，与当前代码的度量单位一致，不是物理屏幕像素。行高是最小值，实际字形或公式较高时扩大。

| 内容 | 字号 / 最小行高 | 目标字重 |
|---|---|---|
| 正文、列表、引用正文 | 18 / 30 | Regular，约 400 |
| H1 | 32 / 44 | Semibold，约 600 |
| H2 | 26 / 38 | Semibold，约 600 |
| H3 | 22 / 34 | Semibold，约 600 |
| H4 | 20 / 32 | Semibold，约 600 |
| H5 | 18 / 30 | Semibold，约 600 |
| H6 | 17 / 28 | Semibold，约 600 |
| 表格 | 17 / 28 | 正文 Regular；表头 Semibold |
| 代码块 | 15 / 24 | Regular |
| 全文源码、局部源码 | 15 / 24 | Regular，保留语法高亮 |
| 界面正文 / 辅助文字 | 13 / 20；12 / 18 | Regular；必要的标签 Medium |

正文内显式加粗维持 Bold。标题使用比当前粗体轻的视觉重量；字体没有精确 600 时，按真实字体可用字重选择最接近的中等或半粗字重，并在中英混排样张中检查，避免无意使用过黑的替代字形。

第一阶段行内代码保持所在行字号，调整字体与背景；代码块使用圆角。不承诺行内代码缩小字号。当前 TextRun 共享行字号；后续缩小字号需要真正支持混合字号的行内布局，不能只缩放绘制而沿用旧光标几何。

标题点击展开标记、离开收起、悬停不展开，以及新标题输入策略全部保持。标题进入编辑时仍维持当前标题字号，避免降为正文造成额外跳动。

## 4. 阅读栏与窗口适配

普通模式的内容栏最大宽度为 **760 px**，水平居中；正文 18 px 时，一行约容纳 42 个全角字符，英文实际字数依 shaping 结果而异。

为内容栏左侧预留 40 px 的块类型入口区域，右侧保留同宽平衡空间。可按以下规则计算，参数集中配置：

```text
outer_margin = 24（视口宽度 >= 600），否则 12
gutter = 40
content_width = min(760, viewport_width - 2 * (outer_margin + gutter))
content_left = (viewport_width - content_width) / 2
```

极窄视口先缩减外边距和 gutter，并限制内容宽度为正数；不通过强制最小内容宽度让正文溢出视口。实际最小窗口约束与布局下限共同验证。

- 顶部留白 36 px，底部留白 48 px；末尾添加块继续使用独立命中区域。
- 列表、表格、代码块、Mermaid 在同一内容栏内布局。嵌套块从栏宽中扣除实际容器缩进，不重复扣除页面外边距。
- 首版保留代码折行、表格单元格折行和图表缩放策略；横向滚动、拖动列宽另行设计。
- 全文源码使用可用视口宽度和 24 px 左右边距；局部源码保留对应块的位置与容器上下文。
- 窗口缩放或模式切换时，以可见源码位置为滚动锚点，重新排版后保持锚点尽量处于原屏幕高度。

## 5. 块间距与装饰

| 类型 | 建议间距与装饰 |
|---|---|
| 段落 | 段后 14 px；段内软换行维持 30 px 行高 |
| 标题 | H1/H2 段前 32 px、其余 24 px；段后 12 px；文档首块不附加段前距离 |
| 列表 | 相邻紧凑条目间距 4 px；宽松条目按段落间距；整组前后 14 px；保留悬挂缩进与现有层级关系 |
| 代码块 | 前后 16 px；正文水平内边距 16 px、垂直 12 px；语言标签独立占据空间，不覆盖首行代码；圆角 6 px |
| 表格 | 前后 16 px；单元格水平内边距 12 px、垂直 8 px；浅色表头和细网格；保留 Markdown 列对齐 |
| Mermaid | 前后 16 px；沿用可用栏宽等比缩放与渲染限制 |
| 引用 | 未来结构化实现时采用 3 px 竖线、16 px 内缩；本次字体调整不声称完成引用结构编辑 |

相邻块的间距取前块段后与后块段前的较大值，不简单相加。基于语义 AST 与容器范围区分段落边界、列表内段落和代码空行，不通过字符串空行猜测块类型。

**空行处理必须保留编辑位置。** 普通模式下，块间第一个分隔空行以 14 px 的可命中行盒参与间距；所需额外留白只补到目标块间距。例如段落到 H2 的目标间距为 32 px，分隔行已有 14 px，只补 18 px。连续额外空行仍各保留正文行高，避免清空用户有意留出的空间。空行行盒对应真实源码位置，额外装饰间隙不创建虚构字符；点击间隙就近定位到相邻合法源码边界。

代码内容、硬换行、空列表项和输入中的空段落不按块分隔空行压缩。全文和局部源码模式按原始行逐行呈现。切换模式不删除空行，也不修改换行字节。

建议颜色统一为主题值：页面 `#FAFAF8`，正文 `#30343B`，标题 `#20242B`，辅助文字 `#727780`，展开标记 `#818791`，链接 `#306FA6`，代码背景 `#F0F1EE`，边框 `#E1E4DE`。颜色是初始设计值，需结合真实窗口检查可读性；展开标记仍须清楚可编辑。

## 6. 实现边界与步骤

### 第一阶段：字体、字号和阅读栏

新增 `src/theme.rs`，集中保存文档字体、界面字体、等宽字体、字号、字重、颜色及空间参数；暂不增加设置窗口、下载字体或主题市场。

在 `src/editor.rs` 统一生成文本样式和内容布局参数。Geometry 保存本次布局的 `content_origin`、`content_width` 和排版版本，替代分散的 `CONTENT_LEFT`、`PADDING` 计算。绘制、命中、选区、导航、列表标记、代码背景、表格网格、块菜单、末尾添加区及 IME 候选框定位共同消费同一份几何数据。

普通文本也按实际 ascent/descent 与主题最小行高计算行盒；公式路径保持现有基线混排。字体、宽度或模式变化后重建几何，不能只按源码 SnapshotId 判断几何仍然有效。在新几何可用前，事件不使用旧像素解释当前布局。

### 第二阶段：语义块间距

在 `src/presentation.rs` 增加供布局消费的块边界与间距元数据；复用解析快照和已有列表、代码、表格的语义信息，不维护另一份可编辑富文本。区分真实空行行盒与装饰间距，统一命中和滚动锚点规则；不要直接在逐行循环里遇到标题就无条件追加距离。

### 第三阶段：视觉验收与文档同步

固定同一份 Markdown 样张和窗口尺寸，对比调整前后效果。功能实际落地后同步 README.md、README.zh-CN.md 与 AGENTS.md 的当前状态；保持 GPUI 0.2.2、解析器 0.0.4 和现有依赖锁定。

三个阶段属于同一调整方案，前两阶段都完成后才作为默认排版更新验收。

## 7. 验收标准

1. 在 640、960、1440 px 视口检查栏宽、居中、菜单位置；宽窗口正文不继续拉长，窄窗口不裁切块入口与正文。
2. 样张覆盖中英混排、H1–H6、ATX 与 Setext、粗体/斜体/链接、emoji 与组合字符、行内代码、嵌套列表、表格、代码块、Mermaid 和公式；字形与公式不裁切，标题层级清楚。
3. 有序/无序列表、引用原文和代码块覆盖跨行输入；代码内容按字面保留，换行与嵌套前缀不因排版修改。
4. 检查行首/行尾、折行边界、空行、块间留白、居中/右对齐单元格的点击定位；拖选跨越多个块并包含隐藏标记，替换和撤销保持原有语义。
5. 连续窗口缩放、源码模式切换、标题点击显隐后，光标、选择框和候选框跟随当前布局；拖选与 IME 期间不额外改变显隐策略。
6. 覆盖首尾空行、多重空行、宽松列表、嵌套块、空代码块及 LF/CRLF/CR。纯排版和模式切换后源码字节、dirty 与撤销深度均不变；未修改保存仍保持原始字节。
7. 为内容栏几何、块间距、空行映射和布局失效添加针对性测试。代码落地后执行 `cargo fmt --check`、`cargo test --locked`、`cargo clippy --locked --all-targets -- -D warnings`、`cargo run --locked -- --smoke-test`，以及预期退出 1 的 `--smoke-test-failure`。
8. GUI 冒烟检查只证明真实窗口几何下的回调行为；另外人工检查中文输入法候选窗口、Retina 与非整数缩放下的观感。未执行的人工检查明确记录，不以冒烟测试代替。

## 8. 实施记录

- `src/theme.rs` 集中字体、回退、字号、颜色与内容栏参数；界面保持系统字体，工具栏基础字号为 13 px。
- `src/presentation.rs` 输出语义流块与源码模式样式；同时处理紧凑列表直接包含行内节点、宽松列表包含段落节点的不同 AST 结构。
- `src/editor.rs` 将内容栏原点保存于 Geometry，统一排版、绘制、命中、选区、装饰和 IME 查询；普通文本按实际字形度量扩大行高，修正行顶部与前行底部重合时的命中优先级。
- 语义间距复用原始显示位置，首个块间分隔空行使用 14 px 行盒，额外空行保留 30 px；源码模式逐行保持等宽排版。代码标签的 32 px 区域与底部 12 px 内边距保留，块间距另按语义计算。
- 缩放与全文源码模式切换按可见源码锚点恢复滚动位置；窗口最小尺寸为 520 × 360 px。源码、解析器与锁定依赖版本不变。
- 已通过 83 项单元测试，覆盖栏宽计算、语义块间距、额外空行、列表结构、局部源码以及 LF/CRLF/CR 源码映射。
- 已通过真实窗口冒烟检查，新增字体选择、空行与行首命中、局部/全文源码字号、640/1440/960 px 窗口缩放与滚动锚点验证，同时执行原有行内、标题、列表、表格、代码、Mermaid、公式、IME 回调与撤销回归。
- `cargo fmt --check`、锁定依赖的全量测试及 Clippy（全部目标、警告视为错误）均通过；`--smoke-test-failure` 按预期退出 1。检查使用 Rust 1.99 与独立 Cargo 缓存，从 `/tmp` 执行并指定项目 manifest，以避开用户全局镜像缺失解析器 0.0.4 的问题，未修改全局配置。
- 已通过 `scripts/bundle-macos.sh debug` 更新 `target/Ryne.app`，`codesign --verify` 验证通过；没有关闭或重启用户已有窗口。
- 人工鼠标键盘、实际输入法候选窗口、不同显示器与缩放比例的视觉验收尚未执行；GUI 冒烟结果不替代这些检查。引用的结构化呈现仍属于后续功能。
