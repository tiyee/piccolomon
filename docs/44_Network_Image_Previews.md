# 图片预览与加载失败图标

独占段落的 `![说明](https://host/image.png)` 在光标离开后显示图片，点击或方向键进入时恢复同一份 Markdown。引用式图片链接及列表、引用中的独立图片复用解析器的目的地址和容器范围。完整图片语法原子映射到一个展示对象；原始 Markdown 仍是唯一数据源。

## 实现

- `ryne-syntax::image` 在解析快照内保存独立图片目录。图片须为段落的唯一子节点，或紧凑列表项的唯一正文节点（可含任务标记）；代码中的图片字符串、不完整语法及与正文混排的图片保留原文。
- `PreviewSource` 把预览范围、容器范围、编辑锚点和缩进从 `CodeBlock` 中分离；图片不伪装为围栏代码。
- `PreviewProvider::document_inputs` 提供非围栏候选，与原围栏候选按源码位置和注册优先级合并。候选范围受宿主校验；缓存继续按提供者、源码身份和声明代次隔离。
- `ImagePreview` 注册图片提供者。`ImageRenderer` 在既有后台串行队列中加载 HTTP(S)、FTP、`file:` 和 `data:` 图片、识别格式并解码；UI 只消费平台无关像素值，不导入网络或图片解码服务。
- PNG、JPEG、GIF 首帧、WebP 和 SVG 转为共享预览使用的非预乘 BGRA。应用 EXIF 方向，保留比例和自然尺寸；展示时按正文栏扣除容器缩进及引用右侧内边距后的可用宽度等比例缩小，小图不放大。极窄文本区取消 40 px 最小图片宽度；缩进过深时收敛到保留 1 px 内容空间，图片右边缘始终不超过正文栏右边缘。PDF 导出复用同一资源和分页实现。
- 源码模式、局部源码、选区、拖选和 IME 沿用现有资源可见性及冻结规则。旧任务取消或换文档后不能发布到新文档。改变地址会使用新资源键；显隐和下载不产生 dirty 或历史。

## 边界

每张图片加载/解码前最多 8 MiB；HTTP(S) 最多跟随 5 次跳转，地址不含凭据。普通 URL 最多 8 KiB；Data URL 最多 24 MiB 加 8 KiB 头部，解码仍限制 8 MiB。每文档候选地址合计最多 32 MiB，避免内嵌数据无限复制到候选与任务键。解码前限制单边 4096 px、总计 1600 万像素；解码器申请 128 MiB 分配预算（第三方解码器不保证所有内部临时分配均计入）。超过 200 万像素的图像等比例缩小后进入缓存，原比例仍用于排版。图片与 Mermaid 共用两秒任务截止时间、每文档 32 个候选及 32 MiB 像素缓存。网络超时或解码失败时收起图片语法，显示 `image_failed.svg`，后接带删除线的红色地址。地址按 grapheme 保留前 256 个字符，超出部分以 `…` 表示；点击图标或地址（含折行后的任意一行）进入完整 Markdown 源码，离开后恢复失败提示；局部/全文源码隐藏提示，不持续重试；修改地址或重新打开可重试。同步解码不保证强制中断。

- `file:///...` 使用平台 URL 路径转换，支持中文、空格及百分号编码；只读常规文件，读取前后检查类型/长度，并在读取中限制字节数。相对路径仍保留源码。
- `data:` 使用 data-url 0.3.2 流式解码 Base64 或百分号编码，兼容 MIME 参数和 URL 片段。实际文件内容决定图片格式，不依赖扩展名或 MIME 标签。支持 `data:image/svg+xml,...` 与 `data:image/svg+xml;base64,...`。
- FTP 使用 suppaftp 12.2.1，不依赖系统命令。支持匿名或 URL 中的用户名/密码、端口、UTF-8 百分号编码目录/文件名及 `;type=i`；先 EPSV，IPv4 服务器不支持时回退 PASV，数据连接使用控制连接的同一主机。检查最终完成回执后才发布；取消或两秒截止关闭控制和数据连接，持续发送少量字节不能延长截止时间。DNS 等待也受截止约束，但平台解析调用本身由后台线程完成，不能强制取消。仅支持 FTP，不包含 FTPS/SFTP。
- SVG 使用现有 usvg/resvg 0.45.1 转像素，支持透明度、viewBox、路径、文字和内嵌位图。SVG 输入最多 2 MiB，XML/展开树最多 20,000 节点、64 层深度、200,000 路径段；受隔离图层面积和图片总尺寸限制。尽量使用 2× 栅格，最多 200 万缓存像素。内嵌位图经同一有界解码器，合计最多 8 MiB 像素；不加载外部文件/网络资源，不递归内嵌 SVG/SVGZ。同步解析和栅格化仅在边界检查截止时间，不承诺强制中断或第三方临时分配的严格总量。

当前不支持相对路径、SVGZ、动画播放及与文字混排的行内图片。这些情况保留可编辑原文。导出使用独立冻结服务重新加载图片，失败项导出带删除线的红色地址提示，不绘制交互图标。保存不下载或嵌入图片，也不改写链接。

## 验证入口

- 语义测试：独立/引用式图片、嵌套容器、代码字面内容、不完整语法和 LF/CRLF/CR。
- 会话测试：原子映射、重复 URL 缓存、点击对应的源码定位、局部/全文源码、地址修改及撤销、原始字节保存、失败收敛、冻结和取消、独立导出快照。
- 服务测试：透明度与颜色通道、格式和大小限制、取消、大图降采样、编码文件名、两类 Data URL、超过旧 8 KiB 限制的内嵌图片、自包含 SVG，以及本机 HTTP/FTP 协议、完成回执、被动模式回退与截止测试。
- `cargo test --locked -p ryne-services user_example_downloads_and_decodes -- --ignored --nocapture` 单独检查用户提供的公开地址；普通测试不依赖外网。
- `RYNE_SMOKE_IMAGES_ONLY=1 cargo run --locked -- --smoke-test` 使用确定性像素服务在真实窗口验证绘制、等比例适配、点击展开、离开收起及源码切换；完整窗口冒烟包含同一组检查。该检查不是人工输入法验收。

`assets/icons/image_failed.svg` 参考用户提供的「图裂了.svg」，采用项目统一的 1024 画布、64 单位线宽、圆角和 `currentColor`。以 24 px 显示在地址左侧，预留 32 px 水平空间。失败地址作为原子映射覆盖完整图片源码，独立保存容器范围与编辑锚点；截断和显隐不修改原始 URL、源码、dirty 或历史。错误预览通过 `PreviewInput::fold_errors` 复用预览的焦点/冻结规则，代码块诊断保持原有行为。

可设置 `RYNE_SMOKE_IMAGES_URL` 为实际图片地址，在窗口检查中启用生产图片加载器。
