# 脚注呈现、导航与编辑实施规划

日期：2026-11-15。状态：规划；已完成 FN0 的 22 例锁定后端探针与静态可行性复核，FN0 尚未整体放行，FN1–FN5 未实现；本文不作为脚注已支持的说明。证据与剩余门槛见[可行性报告](reviews/footnotes/README.md)。

目标是让长文中的脚注可读、可定位、可返回，并能直接编辑同一份 Markdown。源码继续是唯一数据真相；编号、引用目录、跳转记录及视觉装饰均为派生状态，不在保存时重排定义、改写标识符或生成另一份正文。

参考 VeloType 固定提交 `07a24a9b5b953539dede8e61a1f7d9d0adbba590` 的[脚注目录](https://github.com/manyougz/velotype/blob/07a24a9b5b953539dede8e61a1f7d9d0adbba590/src/components/markdown/footnote.rs)：分离原始标识符、显示编号、定义位置和引用出现位置。Ryne 采用源码锚点而非 GPUI EntityId 作为业务目标，并扩展为返回实际来处，不能只回到同一脚注的首次引用。视口联动见[区块树设计](reviews/block_tree/DESIGN.md#611-屏外焦点与交互保留2026-11-15-补充待实现)。

上述表格为当前主程序源码核查。另已在独立探针中核实 pulldown-cmark 0.13.6 的 22 组事件与源码范围，启用选项为 `ENABLE_FOOTNOTES`，不启用 `ENABLE_OLD_FOOTNOTES`。尚未验证新节点的 token/字段来源、完整源码往返或编辑命令，不能把后端事件有效当成 FN0 全部通过。

探针发现未启用脚注时，`a[^x]` 与 `[^x]: note` 可以被解释为普通引用式链接；启用后语义改变为脚注。这是编辑器显式选择扩展方言的行为变化，必须记录并测试，不能描述成原来所有脚注形式都只是原文。默认解析入口与 GFM 基线保持不变。

首版范围：正文中的有效 `[^label]` 引用、顶层 `[^label]: 正文` 定义、多次引用、定义的多段/列表/引用/代码等解析器确认的子结构、编号、就地编辑、往返导航和 PDF 保真回退。列表、引用、表格单元格中的引用在能提供完整映射时支持。定义位于其他容器内部时，该定义及绑定到它的引用整体保留源码；定义中的脚注引用按原文字面呈现，不计入正文编号、来源列表或导航关系，不递归展开。不得影响同一文档中其他有效脚注。

浮动预览、页底脚注自动分页、脚注插入/全局改名命令、自动清理无引用定义及 HTML 导出不在首版范围。PDF 首版在定义原位置输出，不自动搬到页底或文末。

## 2. 语法、解析与全局编号

```markdown
第一处说明[^note]，另一处也引用同一注释[^note]。

另一条注释[^other]。

[^other]: 定义可以先写，但显示编号按正文首次引用确定。

[^note]: 第一段，允许 **粗体** 和 `代码`。

    第二段沿用解析器确认的脚注续段缩进。
```

拟议解析契约：

1. 解析器增加显式脚注选项；现有构造入口与默认 GFM 0.29 样例保持原行为，编辑器通过统一解析配置显式启用。正常解析、候选验证、Undo/Redo、临时 IME、裸 CR 兼容视图和导出冻结配置必须一致；不能只有打开文件时开启。
2. 完整适配后端的定义容器、引用事件及结束事件，保存原始标记、标签、正文、容器前缀和续段范围。新增节点后审计所有 NodeKind/SyntaxKind 匹配、token 分区、源码序列化、格式化验证和源码回退，不能让未知事件分支吞掉字符。
3. `raw_label` 保存原字节范围，匹配使用后端事件给出的已规范化标签配合与后端一致的 `UniCase` 相等性。已核实 ASCII 空白折叠、Unicode 大小写匹配（如 `straße` / `STRASSE`）、一般反斜杠保留及表格内 `\|` 特例；不得用 `to_uppercase` 代替，也不把事件标签长度当作原始范围长度。若新增直接依赖 `unicase`，使用当前锁定的 2.10.0，不升级后端。完整语料和字段来源通过 FN0 后才开放。
4. 从完整已提交语义快照建立目录，不随视口或当前局部源码范围截断。按正文源码顺序，对首次出现且可唯一解析的脚注分配 1 起的编号；同一脚注后续引用复用编号。定义在文件中的顺序不影响编号，无引用定义不占编号。
5. 重复定义首版采用保守策略：先收集所有定义（包括首版不支持的容器内定义），再判重和过滤资格。同一查找键有多个定义时，该键的引用和定义保留可编辑源码并标记歧义，不静默选择其中一个。不能先丢掉嵌套定义而把剩下的顶层定义误判为唯一。重复项删除后重新解析、恢复正常呈现；这是 Ryne 首版边界，不声称所有脚注方言都采用此规则。
6. 未定义引用、不完整标记、无法证明映射的定义和无引用定义保持原文。已核实未定义引用在当前新语法中只发出 Text 事件，首版不对这些文字追加脚注目录或专用诊断。空定义虽然能产生定义事件，但没有正文锚点时整组保留源码，不渲染成不可编辑空面板。代码、转义文本、HTML 原文和公式中的类似文字不计入引用；不得从文字字符串另扫出“脚注”。
7. 增删前方引用可能改变后续编号；编号只影响展示及布局依赖，不回写标签。首版允许按快照全文重建目录，记录耗时，不声称局部解析已完成。未知或含糊依赖保守失效。

拟议目录包括定义完整源码范围、标签/正文范围、所有引用出现范围及其定义绑定、显示编号和诊断。每个引用出现位置分别寻址，不能只存“标签 → 首次引用”；文档身份和快照身份参与所有公开查询。`BlockDirectory` 可作为辅助定位，不能把当前尚未支持的脚注 BlockKind 当成已存在 API。

### 2.1 FN1 的前置改造

- 引入值类型解析配置（至少 dialect、math、footnotes），由 EditingState/快照持有，派生解析继承它。必须覆盖 `EditingState::new`、`features/commands.rs::apply`、输入补全候选、列表/插入验证、排版语义比较、`session/basic.rs`、Undo/Redo、composition、裸 CR 语义视图及 `export_snapshot` 重建。当前这些路径散落调用 `with_math`，不能只替换打开文件入口。配置不在保存时写进 Markdown，默认公共构造入口保持旧语义。
- 新增定义头部与续行缩进的字段来源/容器 token。当前 `syntax.rs` 的容器前缀扫描只识别 BlockQuote/Item；列表、代码、表格等功能又依赖这些 token，故脚注内结构不能不经审计地直接复用。定义范围可能包含尾部空行、lazy continuation；不能见到非缩进行就退出或对每行固定删除四空格。按解析边界记录原始前缀及正文，区分结构缩进与字面代码缩进。
- 对不支持/歧义定义及关联引用，源码回退须覆盖对应区域并压过内部隐藏规则；否则内部列表/代码贡献仍可能隐藏一部分前缀。回退不重新用另一套方言解析这一区域，避免全文关系与局部解析冲突。对未知新节点的全文安全回退是兜底，不作为脚注首版正常呈现。

## 3. 呈现与源码编辑

引用收起时显示上标编号，使用当前字体度量和主题链接强调色；10、100 等多位编号参与真实排版和行高。整个编号映射到完整 `[^label]` 范围，采用双亲和性边界，不允许落到虚构数字中编辑。编号生成文本不进入保存或复制的源码。

实现前须补显式脚注原子对象，而非只加 `Style::link`：当前普通与 IndexedDisplay 的等长 span 会逐字节映射，grapheme 导航也会遍历多位数字。新增原子区间须同时进入双向映射、合法停靠点、删除/选择、投影验证与命中，使 `[^x]` → `1000` 这样的等长替换也不能进入数字内部。不能借用 math/diagram 标志伪装脚注。

当前 GPUI 正文 TextRun 没有本项目可用的逐 run 字号/基线位移路径；现有 MixedLine 仅处理 Text/Math。因此 FN2a 必须扩展混排行内对象，编号作为可选择文字单独度量并上移基线，纳入折行、行高、命中、选区、缓存键和打印布局；不转为图片或数学 SVG来绕过文本语义。缓存键至少包含编号文字、字号、基线偏移、字体与主题依赖。PDF 未接入时回退完整脚注源码，不能假装已有上标打印能力。

| 操作/状态 | 首版行为 |
| --- | --- |
| 普通点击引用、键盘移入引用 | 展开完整 `[^label]` 以编辑；不默认跳走，遵循现有行内标记编辑习惯 |
| 光标离开引用 | 能唯一解析时恢复编号；无效/未定义时保留原文 |
| 悬停引用 | 提示“前往脚注”及平台修饰键，不展开源码；拖选/IME 时不新增浮层 |
| macOS Cmd+点击 / Windows Ctrl+点击，或引用上下文菜单“前往脚注” | 只读定位定义，保留正文焦点与原源码选区；可通过键盘打开菜单执行同一动作 |
| 定义正文获得光标 | 保持脚注容器与编号呈现，正文和内部块结构直接编辑，内部行内语法沿原规则显隐 |
| 点击定义编号/标签入口 | 展开定义的完整局部源码，定位标签；入口包含完整续段、缩进和容器上下文 |
| 定义正文首位置 Backspace/向前导航 | 先展开头部或局部源码，不直接删除隐藏 `[^label]:`；再次操作按源码规则 |
| 局部/全文源码模式 | 引用和定义标记全部可见，隐藏派生编号/返回装饰；换行按原始换行约定直接写入 |
| 多引用、跨块选择与复制 | 使用统一源码范围；覆盖完整引用时包含完整标记，定义复制保留续段前缀 |
| 拖选/IME 预编辑 | 固定必要显隐状态；确认后更新语义与编号，候选确认 Enter 不触发跳转或新段落 |

定义保持文件中的原位置，不额外复制一份“文末脚注区”。定义前显示一次编号及脚注类型入口；正文复用既有排版，不每段重复标题，嵌套内容共用外层定义入口。暗/亮主题和字号切换使用统一主题，图标遵循现有 SVG 规范，具体资产在 FN2 选定，不预设仓库已有脚注图标。

定义正文的 Enter/Shift+Enter 是 FN2 的必做项：普通正文换段/硬换行保留解析器要求的续段缩进与原换行；非空内层列表/引用/代码优先沿用其结构命令；空续段退出定义时保留外层上下文。首行操作不得重复插入 `[^label]:`。不能证明候选结构与定义边界时拒绝结构命令并提示使用局部源码，不猜测修改缩进。所有正文修改一次事务可撤销；自动补齐脚注标记不在首版范围。

## 4. 跳转、返回与屏外焦点

阅读导航不改源码、dirty 或撤销栈。首版跳转仅滚动并短暂强调目标，保留原编辑选区；用户实际点击目标正文后才转移编辑位置。新滚动意图不得被此前挂起的“显露原光标”请求覆盖。

### 4.1 精确返回

每次成功的引用跳转保存来源引用的源码锚点/亲和性、目标定义身份、视口顶部源码锚点及局部屏幕偏移、文档身份和导航代次。来源为“这一次点击的引用”，同一脚注的第二处引用返回第二处，而不是第一处。仅在目标已经验证并完成定位后压栈，失败或被取代的请求不压栈。

- 定义旁“返回引用”优先取当前定义最近一次有效到达记录；没有记录时，一个引用直接定位，多个引用展示按源码顺序的来源列表。不能无提示固定跳到第一处。
- 只读往返不改变当前源码选区；如果用户在定义正文开始编辑，返回也只滚动，不恢复旧选区或撤销用户的新编辑。返回提示说明是导航动作。
- 返回记录最多 32 条，超出丢弃最早记录；匹配的返回成功后消费该记录，其他有效记录保留。Escape 仅沿现有菜单/局部源码规则处理，不另占为全局脚注返回键。
- 每次已提交事务映射记录锚点，并重新验证引用出现及定义绑定。来源引用完整 token 被修改/替换时使记录失效；定义身份以头部标签范围与当前语义容器校验，修改定义正文可以保留返回记录。禁止按相同标签或相同正文猜测复活，Undo 后也不复活已失效的旧记录。
- 文档替换/关闭清空栈；切换源码模式、主题或窗口尺寸保留合法源码锚点，丢弃像素缓存。返回优先恢复仍有效的视口锚点与偏移，无法恢复时重新定位来源；来源已失效则提示并不跳到相邻字符。

跟踪锚点不是当前公开 API 已有能力：`SessionEvent` 只有新文档身份/序列/事件类型，未携带 PositionMap。FN3 先实现会话拥有的有界锚点表，UI 栈保存不透明句柄及视口偏移；在 `publish_plan_inner` 与 `try_undo` 中借用候选 PositionMap 和 `unchanged_ranges` 准备新表，通过验证后与 Source 原子发布。IME 确认复用发布路径，取消不改已提交锚点。失败事务不前移锚点，删除/等字节替换也不能凭位置映射判为同一次引用。

映射完成立即释放 PositionMap，不在 32 条记录中长期保存它及其 old/new `Arc<str>`；不要求阶段 D 的持久位置树。UI 释放/消费记录同步释放锚点句柄，文档替换整体清空。只保留已注册的少量锚点，不建立全历史逐键映射链。

### 4.2 两阶段导航与 IME

导航请求携带文档/源码身份、源和目标锚点及请求代次。先查当前目录，再请求目标完整布局单元精排，完成后重新验证目标和用户意图，以当前真实几何滚动；旧请求不能覆盖新跳转、用户滚动或新文档。B3 未启用时同一协议使用完整布局，避免另外建立只适用于虚拟布局的脚注路径。

原光标位于屏外时保留正文输入宿主及其必要布局，目标只在请求期间加入交互保留，导航结束交给可见工作集；返回栈不持有全部历史目标的布局。实际输入、方向键与预编辑更新再按正常编辑规则显露活动光标。

拖选及存在未确认 IME 时禁用脚注跳转/返回动作，不排队在确认后自动跳转，避免误操作或隐式提交候选。滚动仍可进行，候选查询沿 B3 的当前临时几何规则处理。选择禁用只读导航不影响现有文件保存等操作的 IME 确认流程。

事件顺序必须调整：当前 `mouse_down` 首先调用 `commit_composition`，脚注修饰键命中预检要在它之前执行。识别为导航且正在预编辑/拖选时消费该导航意图，不能降级成普通点击而提交候选或移动选区。普通点击仍走原编辑逻辑。现有 RenderControlPlacement 没有任意行内引用位置、CommandPlan 也没有只读滚动结果；FN3 须增加经当前帧/目标校验的行内命中及类型化导航请求，不能用 Select 冒充只读跳转或在 UI 匹配业务字符串。键盘入口通过当前引用/定义的动作菜单提供，菜单按键路由和七语言提示是实现项，不假设现已有通用行内菜单。

## 5. 分层职责与导出

| 层 | 拟议改动 | 不得承担的职责 |
| --- | --- | --- |
| `ryne-parser` | 显式脚注扩展、语义节点、token/字段来源和源码往返 | UI 编号绘制、GPUI 焦点 |
| `ryne-syntax` | 快照只读 FootnoteIndex、定义/引用绑定和歧义诊断 | 可独立编辑的脚注正文、视口裁剪后的全局编号 |
| `ryne-projection` | 编号原子对象、定义正文与标记显隐的双向映射 | 从编号生成原始标签或保存文本 |
| `ryne-features` / `ryne-extensions` | 声明式脚注入口/菜单、导航意图及源码编辑计划；必要时扩展类型化 UI 请求 | 在通用 UI 中匹配业务字符串执行源码修改 |
| `ryne-session` | 统一解析配置、候选验证、原子发布、历史及 IME；有界跟踪锚点表与只读导航请求校验 | 另一份可变脚注数据真相、持有全历史 PositionMap |
| `ryne-ui` | 主题呈现、当前帧行内命中、修饰键预检、导航句柄栈、滚动与交互保留、七语言提示 | 直接写源码、靠旧像素或只凭新快照猜锚点 |
| `ryne-services` | PDF 冻结同一解析配置/编号目录，定义原位输出或完整源码回退 | 依赖当前屏幕挂载集合或实时导航栈 |

表中类型名称均为拟议接口；实现前审查依赖方向，不允许 services 或 syntax 反向依赖 UI。

PDF 首版优先复用编号和定义正文的原位呈现，保留可选择文本、完整多段正文及跨页内容；无法正确呈现的脚注按完整源码输出，不能只留下编号而漏掉定义。冻结快照使用同一份引用顺序与语义状态，不随导出期间的编辑或屏幕滚动变化。页底脚注、跨页回链与 PDF 点击动作后续单独设计，不能因编辑器支持点击就宣称 PDF 也支持。

排版命令应保留脚注原标签、定义位置与续段边界；首版对不能证明语义等价的相关变更整体拒绝。草稿恢复保存源码即可，重新打开后重建目录，不持久化临时编号和导航栈。
