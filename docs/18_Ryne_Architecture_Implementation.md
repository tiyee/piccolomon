# Ryne 分层架构实施记录

日期：2026-10-13。设计基线：[17 · 分层与插件架构 v2](17_Ryne_Layered_Plugin_Architecture_v2.md)。

本轮在当前 `master` 分支实施，保留开始时已有修改和删除。按用户要求直接采用私有 workspace，所有应用包统一使用 `ryne-` 前缀；没有恢复 C++，没有提交或切换分支。外部依赖锁文件的 828 项版本与校验和保持不变。

## 包与职责

| 私有包 | 当前职责 |
|---|---|
| `ryne-app` | 根应用装配；注入内置功能、公式、围栏预览、高亮与存储实现；二进制仍为 `ryne` |
| `ryne-core` | 唯一已提交 Source、DocumentKey、源码/显示/UTF-16 坐标类型、候选事务、逆事务历史、保存基线 |
| `ryne-syntax` | 现有解析器适配、裸 CR 同宽语义规范化、块/列表/代码/表格/公式的 AST 范围和容器上下文 |
| `ryne-projection` | 通用样式与展示映射、文本流/代码/列表/表格/原子对象模型、平台无关 SVG 与像素资源 |
| `ryne-extensions` | 只读 EditingState、CommandPlan、InputDraft、静态注册图、块 UI 元数据、类型化服务/验证/通知端口 |
| `ryne-features` | 只读规划适配器；结构命令、行内/标题输入、语义呈现、围栏预览绑定及插入模板 |
| `ryne-services` | Formulary + math-core、Merman、Tree-sitter、同目录独占临时文件写入与重命名 |
| `ryne-session` | 一致性提交、选区/显隐/闭合标记检查点、IME 临时状态、串行保存、通用有界任务宿主、提交后通知 |
| `ryne-ui` | GPUI 视图、输入桥接、字体、布局/命中、绘制、资源上传、文件交互及真实窗口冒烟 |

所有包均 `publish = false`。生产依赖只能向下：UI 依赖会话与协议；会话不依赖内置功能和服务实现；核心不依赖语义、投影或 GPUI；具体渲染库只在服务包。会话的测试使用功能/服务 dev-dependencies，生产代码不使用它们。`scripts/check-architecture.py` 从 Cargo metadata 检查这些边界。

## 实施落点

- P0：保留原 88 项单元测试和 124 阶段真实窗口回归，先运行原实现建立基线。新增固定语料 headless benchmark，以及可选 `RYNE_PROFILE=1` 的 refresh/layout/paint 计时。对照数据与采集方法保存在 [性能记录](reviews/architecture-perf/README.md)。
- P1：将原 editor 的输入桥接、排版、绘制、字体、资源、文件交互和冒烟拆开；根入口只负责装配。GUI 资源转换与图标仍由 UI 管理。
- P2：文档核心私有地持有已提交正文。功能只规划不可变旧快照上的候选；会话校验版本、匹配语义、UTF-8 选区、显隐范围和闭合标记检查点，运行全部验证器后，一次发布源码、状态与历史。Undo/Redo 先准备一致的恢复状态，再修改历史栈。源码范围跨命令接口携带文档身份。
- P3：启动注册先检查依赖、重复、循环、内部 API 兼容及独占冲突，贡献只在全部成功后发布。槽位内显式依赖/顺序优先，无约束者按优先级与稳定 ID 排序。未注册 Markdown 功能时，`SourceEditing` 仍支持源码编辑、选区与撤销。观察者只有只读快照，失败不会回滚已发布内容。
- P4：通用围栏预览宿主按功能、服务代次和正文区分资源，串行执行、取消过期目标、验证像素尺寸与预算，并在当前 AST 上重绑定范围。UI 不扫描 Mermaid 语言，不管理 Mermaid 专属线程；帧通过 Arc 保活资源。测试用 alpha/beta 两种预览复用同一宿主。公式、高亮和文件服务通过构造注入；块菜单和类型角标消费声明数据。
- P5：代码、列表、表格、段落、标题、行内补全和模板迁入功能包；旧的可变 Document 路径已移除。输入草稿固定原文档替换范围，规范化和补全更新插入文字及内部坐标，最终只准备一次事务。结束标记越过与导航返回非编辑计划。IME 预编辑留在会话临时状态，确认文字经同一输入通道提交。

上述阶段以当前应用能力为范围，接口仍是内部静态聚合与受控规划适配器，不宣称每种未知插件都能只注册元数据完成编辑或布局。新增同类围栏预览可复用现有服务与任务协议；新增交互结构仍需补足模型、命中和导航协议。

## 一致性与工作流

源码与匹配语义同步发布。投影覆盖文本、映射、结构和资源身份；布局记录源码身份与投影代次。鼠标、导航和 IME 只使用匹配几何。仅移动光标且投影不变时复用几何；预编辑改变投影后拒绝旧帧。取消预编辑恢复完全相同的投影时，可安全复用原几何。闪烁不改投影代次、源码或历史。

GUI 保存移至后台，每个文件会话只有一个活动写入和一个合并为最新请求的待写入。回执绑定实际写入快照；保存中的新编辑仍 dirty，失败不改变基线。Save As 和打开回调检查文档身份；读取期间发生编辑/预编辑或开始保存时不替换文档。保存完成只有当前 clean、无预编辑时才执行先前请求的关闭。临时文件仍在同目录独占创建，保留权限，失败清理，保存不格式化正文。

裸 CR 兼容集中在语义适配层。原始 Source 仍用于事务和保存，LF/CRLF/CR 不被规范化。公式仍保留 STIX 字体、缺字与降级回退；Merman 仍保留已有输入、复杂度、尺寸和缓存限制。两秒取消/截止检查不能中断 Merman 0.7 的布局内部。

性能采样发现行内查询重复提取整份表格语义。本轮让一次查询/投影共用表格提取结果，并让表格提取共用一次列表提取；规则与 AST 数据保持原实现。编辑快照使用 Arc 共享语义，光标规划不复制整份节点向量。

|---|---|
| `python3 scripts/check-architecture.py` | 9 个私有包及生产依赖边界通过 |
| `cargo fmt --check` | 通过 |

## 保留限制

引用结构编辑属于 P6 独立增量，仍未完成；块拖动、表格增删工具栏、跨单元格 TSV、大文档优化、完整 Bidi 与无障碍编辑也没有因此完成。继续保留源码可编辑回退。

本轮按用户要求提前采用私有 workspace，但未引入运行中卸载、插件市场、第三方进程协议或稳定 SDK。静态注册的依赖与能力声明不构成安全隔离。

性能数据是同机 debug 固定语料和窗口场景的局部对照，没有建立全局延迟预算，未完成大文档/超长段落的系统性能验收。公式与高亮仍保留现有同步调用与缓存策略；后台渲染不提供硬抢占。后续应据采样继续改进，不能将本轮数字解释为所有文档的性能承诺。

代码语言自动补全通过只读 `CodeLanguageDetector` 端口注入 Markdown 功能，具体 Tree-sitter
识别在 services 中。粘贴或代码换行后，功能只检查本次修改涉及的未标注闭合围栏；内容输入与语言插入
合并为一次候选提交，统一恢复选区、显隐范围和结束标记检查点。已有语言、源码模式与纯视图操作不补语言。
识别要求完整语法和特征节点；有歧义、不完整及超 32 KiB 的正文回退。每次输入最多尝试八块，单次
识别含解析进度回调与遍历截止检查，限时 50 ms。复用现有 grammar 版本，不增加识别模型或网络请求。

## 多语言增量（2026-10-13）

`ryne-ui/src/i18n.rs` 集中维护七种界面语言：简体中文、繁体中文、英语、日语、韩语、法语和西班牙语。
工具栏提供即时切换与跟随系统选项；macOS 首次启动读取 AppleLanguages，按支持的语言顺序匹配，
识别中文脚本、地区及 POSIX 语言标签，无可用匹配时回退英语。明确选择以同目录临时文件和重命名
保存到 `~/Library/Application Support/Ryne/language`；恢复跟随系统也会持久保存。配置不可写时，
本次切换仍生效并报告错误。界面选择不进入 Source、文档历史、dirty 或 IME 临时状态。

工具栏、模式提示、块/添加菜单、文件提示、状态消息、欢迎示例和新插入占位文字已本地化。
状态保存消息键和独立错误详情，切换后可重新翻译已有状态；系统与渲染器技术诊断保留原文，
原生文件面板自带控件仍由 macOS 管理。应用包声明七种本地化语言。

`TemplateLabels` 是扩展层的声明式文字数据，`AppendLocalized` 经功能规划与会话验证提交；
UI 不拼装可写的 Markdown 块结构。原 `Append` 继续保留已有默认行为。
插入模板的 UTF-8 正文选区、容器分隔、LF/CRLF/CR 和单次撤销保持原有约定，
切换不会重新翻译或替换当前文档（包括尚未保存的欢迎示例）。

本次验证：架构检查、格式检查、107 项单元测试和 Rust 1.99 配套 Clippy 全目标检查通过。
真实窗口冒烟扩展到 129 阶段，逐一显示七种语言并验证持久选择、系统重置，以及 Unicode/CRLF
源码、选区、撤销/重做和预编辑状态保持不变；仍不能代替各语言的完整人工交互验收。
`target/debug/ryne --smoke-test-failure` 正常报告注入失败并以预期退出码 1 结束。
调试应用包已重新生成并验证 Info.plist 和签名，未终止用户已有窗口。
