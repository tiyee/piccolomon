# 一键源码排版与规则

工具栏在源码/视图切换入口之前仅显示 `format.svg` 图标，悬停显示本地化的“排版”提示。
点击在当前文档全文上执行，源码与视图模式均可使用；不会保存文件或改变模式。
结果通过既有 `EditIntent::FormatSource`、功能层 Planner 与会话统一事务提交，
支持一次撤销/重做，映射正向/反向选区、Unicode 光标及局部源码范围。
无需修改时保留文档身份、dirty、撤销与重做历史。IME 预编辑及拖选期间不执行。

## 规则与默认策略

规则位于 `crates/ryne-features/src/commands/format.rs` 的静态 `RULES` 中。
每项有稳定 ID、作用类别和只读补丁收集函数；不新增依赖或修改解析包。
当前使用内置默认规则，尚未提供规则设置面板、外部配置文件或动态插件加载。

| 规则 | 默认行为 | 歧义与保护 |
|---|---|---|
| `heading.missing-space` | `#标题` → `# 标题`，支持 1–6 个 `#` | 仅解析为独立单行段落、正文紧接 `#` 时触发；排除纯标记、7 个以上 `#`、`#!`、多行段落、代码、HTML、表格、front matter。该规则明确允许段落转为标题。 |
| `task.missing-space` | 列表开头 `[x]done` → `[x] done`，支持 `[X]` / `[ ]` | 只匹配解析器确认的首行列表前缀；段落中的方括号、代码、续行保持原样。该规则明确允许普通条目转为任务条目。 |
| `markers.canonical` | 已识别 ATX 标记后的空格规范为一个；无序列表采用 `-`；下划线强调改为星号 | 空标题和 Setext 保留；不同符号用于分隔相邻独立列表时，两份列表的符号都保留；不改有序编号、容器缩进或代码；复杂分隔符须通过完整语义校验。 |
| `fence.backticks` | 闭合围栏统一为反引号，至少三个 | 围栏长度超过正文中行首反引号串；保留语言字段、缩进和正文全部字节（含首尾空行）。信息字段含反引号、未闭合围栏或缩进代码保留。Mermaid 只处理围栏，内容不变。 |
| `table.padding` | 规则管道表格补齐外侧管道、单元格空格与列宽，保留列对齐冒号 | 沿用既有解析器确认的完整单元格范围，保留转义管道、代码、行内格式、`<br>`、空单元格及容器前缀；列数不齐保留原文。列宽按 grapheme 计数，非终端宽度或字体像素。单表补齐估算超过 4 MiB 时保留原文。 |
| `blocks.blank-lines` | 文档级连续空行最多保留一行 | 只处理文档所有的 Trivia；不删代码、HTML、列表或引用内部的空行，也不重排普通段落的软换行/硬换行。 |

保护策略优先于规则：文件开头 `---` / `+++` 的 front matter 保留至闭合边界，
未闭合时保留至文末；支持 BOM。未被规则匹配的字节不重写，不添加最终换行，
不统一 LF / CRLF / CR，不修改引用定义、链接目标、数学内容或代码正文。
列表缩进暂时保留，而不是强制两空格：有序编号宽度、嵌套容器与缩进代码都影响缩进语义。

## 校验与提交

1. 在不可变快照上收集明确授权的结构修复补丁，生成预期语义基线。
2. 收集规范格式补丁，保留每段未修改字节，过滤 front matter 范围。
3. 在隔离 Planner 上准备一次候选事务；重新解析并与修复基线比较完整节点种类、
   文本/代码/公式/链接等载荷、父子关系、列表起始编号、任务状态和表格对齐。
4. 除注册修复之外出现语义变化时，整次拒绝，并在状态栏报告错误；源码、选区及历史不发布。
5. 通过检查后，由会话统一验证和原子提交；表格选区末端采用上游边界，避免新增补齐空格被选中。

输入及最终源码限制 1 MiB、20,000 个语义节点及物理行；补丁替换文本合计限制 4 MiB。
这些是同步交互的资源保护，不代表大文档性能已经完成优化。

## 扩展方式与验收

新增规则应提供独立 ID 和只读补丁收集函数，明确属于保持语义还是修复结构。
有歧义的写法应制定可测试的上下文策略，而不是直接做全文字符串替换。
新的结构修复只有在 `RULES` 显式注册后才能成为预期语义基线；格式规范规则始终受语义一致性检查。
后续可以在此注册表上增加按规则开关或预设，不必改动源码事务和 GUI。

回归见 `crates/ryne-session/src/format_tests.rs`：标题/任务修复、嵌套容器、代码字面内容、
围栏碰撞、表格与 Unicode 选区、原始换行、正反选区、幂等、撤销/重做、无变化及拒绝后的历史保护。
`crates/ryne-ui/src/smoke.rs` 通过真实窗口执行同一工具栏回调，验证新帧、状态和 IME/拖选保护；
这不等同完整人工点击及输入法验收。图标沿用嵌入式 SVG，并明确设置其颜色。
