## 实现与边界

| 顺序 | 修复 | 保持的行为与成本 |
| --- | --- | --- |
| 1 / R4 | `SemanticQuery::code_language_range` 查询解析快照的代码节点范围索引，代替每个语言控件从头遍历 AST | 按原源码字节提取语言 token，保留容器、围栏类型及原换行；100/200/400/800 个围栏分别检查同等数量候选 |
| 2 / R8 | 当前排版构建表格视觉行的上下目标索引，导航时直接取目标并复用原命中算法 | 同单元格优先，跨单元格边界、并列 top 的源顺序、按 bottom 筛选后按 top 选取上方行等规则保持不变；随排版失效，不跨版本复用 |
| 3 / R9 | 打开、导出、更新检查共用操作槽和带身份的终态回执；后台服务 unwind 转为错误 | 先消费匹配任务的回执再清理 pending；取消、旧回执或重复回执不能清除新任务；打开仍校验原快照、IME 与保存状态，导出仍使用只读快照 |
| 4 / R2 | 注册时一次读取并校验 id/commands，之后使用冻结身份和命令所有权 | 新增提供者不重读原有元数据；运行期 controls、缓存依赖和计划仍按提供者隔离错误，执行仍验证最新 enabled/target |
| 5 / R3 | 区分已识别、已完成但无法识别、预算中断；中断时保留待重试状态 | 重试只用完整 50 ms 预算，单轮相同正文只尝试一次；每个正文最多两次完整预算超时后进入独立耗尽终态，保留普通样式 |

表格索引构建为 O(R log R)，临时空间 O(R)，R 为本次排版的视觉行数；常驻目标表只保存
表格视觉行。无表格时不构建，不额外扫描普通文档。导航仍包含现有目录定位、行内命中与
grapheme 映射，不能将整个按键处理称为 O(1)。

识别的部分剩余预算中断不占用完整预算重试次数；已完成的负结果仍缓存。
待重试、完成与耗尽记录共用原目录上限和正文生命周期，移除的正文释放记录及字节计数。
固定文档中前面的完成结果不再消耗识别预算，因此后续正文可以继续；持续超时不会无限调度。
原有每轮八个识别、4096 项及 2 MiB 正文键限制保留。这里不承诺同步高亮或全文投影的耗时上限。

后台异常处理覆盖可 unwind 的服务 panic 和普通错误；不承诺处理进程 abort、内存耗尽或永不返回的服务。
捕获范围包括打开构建会话、导出快照渲染/编码/写入，以及更新服务调用。没有修改已独立修复的保存队列。

## 回归覆盖

- 语言标记：与旧 AST 全扫描独立 oracle 比较，包括 LF/CRLF/CR、嵌套列表与引用、空正文、
  不闭合围栏、波浪号、反引号和缩进代码；100–800 个围栏验证每块只取一个候选。
- 表格导航：旧扫描 oracle 对照覆盖长普通前缀（最多 10,000 行）、单元格折行、不同高度、
  相同 top、top/bottom 顺序不同及重建失效。真实窗口按本帧实际布局比较上下方向和两个 affinity，
  包含多表格、空单元格、`<br>`、分式及自动折行，最终源码光标位置须与旧算法一致；
  原有 180 个公式的四种宽度分配回归继续保留。
- 后台服务：实际 worker 方法在测试线程中注入读文件、PDF 编码、制品写入及更新服务的
  成功、错误、panic；验证 pending 清理、后续成功、取消/重复/旧回执隔离及文档状态不变。
- 提供者：注册后使身份回调不可用，再覆盖缓存、非缓存、依赖失败、controls 失败、计划执行
  及新增提供者；验证 id/commands 各读取一次，健康控件保留，注册失败不破坏已有注册。
- 识别：注入 1 ns 剩余预算后下一完整轮实际识别成功；确定性模拟永久超时、重复正文、
  重排、新增前置正文、正文变化、移除清理，验证有限收敛及后续正文继续。
