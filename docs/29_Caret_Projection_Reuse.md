# 光标移动的投影复用与几何索引

## 范围

解决光标移动时全文投影和控件重复生成，以及每个列表条目、代码面板重复查找全文几何。
源码仍是唯一数据真相，缓存不改变源码、dirty、选区、历史或事务发布。
内容修改仍全文解析，未实现分块重排、可见区域排版或增量解析。

## 复用边界

- `FeatureEngine::presentation_key` 默认返回 `None`，功能必须显式声明稳定输入。
  内置 Markdown 使用源码身份、全文模式、行内/标题显隐范围、有效局部源码范围及公式服务代次。
  `with_feature` 接入的附加功能默认禁用复用，允许其依赖光标、选区或外部状态。
- `FormulaRenderer`、`SyntaxHighlighter` 默认不声明稳定代次。Formulary 的数学字体参与代次；
  Tree-sitter 在本帧自动识别预算延期时不声明稳定结果，下一次刷新继续处理。
- 会话只保留最近的一份投影和一份控件批次；返回 `Arc`，UI 和排版共用不可变资源。
  投影额外比较图表范围、错误文本和图像资源身份，不按像素内容扫描；不缓存含诊断的失败回退。
  相同会话的缓存接口使用同一个高亮服务实例。
- 控件单独由 `cache_source_controls` 显式声明只依赖源码身份及全文模式，避免光标显隐变化时
  重新生成列表/表格菜单。缓存不会绕过首次生成时的控件范围与提供者校验。
- IME 临时投影和临时控件不缓存；确认和撤销生成新的源码身份。鼠标拖选沿用已有显隐冻结协议。
  原有旧帧、UTF-8/UTF-16 和源码映射保护继续生效。

## 索引生命周期

- `TextLayout::index` 在排版构建后一次生成：展示行起点到首个匹配行、代码块到首末排版行、
  列表条目身份到其全部正文行的最大底部。重复起点保留旧查询的首个匹配结果；折行高度包括完整行高。
  索引与排版一起复用和失效，不跨源码/投影版本重用。
- `ControlIndex` 仅在控件批次资源改变时生成，提供表格单元格、代码标题、列表前置按钮及任务标记查询。
  代码标题保留原来按单元格键排序的优先顺序；列表控件保留提供者原顺序。
- 列表的面板首项回退入口使用已放置控件集合判重，避免逐项扫描全部已有区域。
  普通光标附近没有代码节点时，围栏草稿查询跳过物理行范围分配。

## 验证与复现

会话回归比较缓存结果和完整重建结果，并核对资源身份：正文和嵌套块移动、行内/标题显隐、
局部/全文源码、内容编辑与撤销/重做、三种物理换行、Unicode、数学字体、图表结果、IME、
附加功能及自动语言识别延期。几何索引覆盖重复起点、多行/折行条目、空输入和非连续代码身份。
真实窗口冒烟另外检查光标移动复用投影、控件及正文排版，并沿用列表、代码菜单和旧帧保护检查。

```sh
cargo run --locked --example architecture-perf -- caret-cache
```

100 KiB 和 1 MiB 的普通段落语料；每次操作含两次光标移动和两次投影。
同进程比较完整生成与缓存路径，另比较 800 项列表控件。100 KiB 使用 96 个样本，
1 MiB 使用 8 个样本以限制 debug 运行时间；两组各预热一次。输出构建类型、实际字节数和样本数。
这些无窗口结果不能视为真实窗口输入延迟或大文档性能保证。

2026-10-15，本机 Rust 1.99、x86_64 macOS、debug 的一次对比结果（P50，ms）：

| 场景 | 完整生成 | 复用 | 样本 |
| --- | ---: | ---: | ---: |
| 102438 字节，两次选择与投影 | 257.8697 | 45.2814 | 96 |
| 1048626 字节，两次选择与投影 | 2653.3217 | 463.3306 | 8 |
| 800 项列表控件 | 10.8209 | 0.0001 | 96 |

两种文档规模约降低到原耗时的 1/5.7。缓存路径仍执行选择命令及显隐查询，因此仍随文档规模增长；
这次没有优化这些语义查询，也没有测量完整窗口帧、排版或输入法候选窗口延迟。
列表控件的极小耗时只代表已缓存批次的资源引用返回，不包含帧内区域、菜单及文字绘制。

本次验证通过架构检查、`cargo fmt --check`、`cargo test --locked`（229 项单元测试）、
Clippy 1.99 的全目标零警告检查及完整真实窗口冒烟；失败注入按预期返回退出码 1，无原生事件循环 panic。
本机 `cargo clippy` 优先找到用户 Cargo 目录中的旧 1.81 驱动，实际检查直接运行
`/usr/local/opt/rust/bin/cargo-clippy clippy --locked --all-targets -- -D warnings`，未修改全局工具配置。
