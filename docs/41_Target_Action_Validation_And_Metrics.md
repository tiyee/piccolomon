# 第一批：目标级动作验证与诊断计数

## 行为变化

`RenderActionProvider::controls_for_target` 是可选的实时目标查询。默认返回 `None`，
宿主继续调用旧 `controls`；返回 `Some` 时使用目标结果，空列表表示当前目标不可用。
错误或 panic 拒绝本次执行，不降级到全量结果掩盖失败。

两条路径共用原来的完整控件校验：源码/解析身份、目标范围、提供者和命令归属、控件 ID、
动作数量、focus、预留宽度和局部源码过滤。执行还要精确匹配当前 target/command/enabled；
不会信任缓存菜单状态。源码模式、IME 和旧帧保护沿用原有通路。

内置表格通过快照表格目录二分找到目标表格，再直接索引目标行列，只构建一个控件。
800 正文行、3 列的表格原来为执行验证重建 2,403 个控件、31,239 个动作；现在目标查询
只构建 1 个控件、13 个动作。这是验证阶段的对象工作量，不代表整个操作的延迟同比下降。
初次呈现仍需要完整控件批次，内容修改后的解析、投影和命令自身工作没有被消除。

内置列表只计算目标条目的 extent，生成一个条目前置控件，以及任务条目需要的一个标记
控件。当前仍线性查找条目并扫描同级关系，没有声称列表操作已经达到常数复杂度。
全量和目标查询共用生成函数，保持上下移动、缩进、任务状态及嵌套容器语义一致。

## 默认关闭的诊断

沿用 `RYNE_PROFILE=1`，没有启用时不遍历历史/控件，不读取计数时钟，也不执行原子计数。
原来的计时记录继续使用 `elapsed_ms`；新增：

- `layout_build_attempt`：正文 TextLayout 构建尝试次数，包含失败后的源码回退重试。
- `layout_cache_hit`：正文布局缓存命中次数。两项均为进程累计值，非每个文档独立计数。
- `owned_memory_sample`：每次 refresh 末尾记录文档身份、revision、源码长度、undo/redo
  条数、历史保留分配字节、当前发布控件/动作数和该批次的保留分配字节。

历史字节按两条栈的 capacity、逆向 Edit 数组及 replacement capacity、checkpoint 的
closers capacity 统计。控件字节按当前聚合 Vec、id、part、actions 和 Header label 的
capacity 统计。共享静态标签不重复计算；查询不修改历史、dirty、选区或保存状态。

这是明确限定范围的拥有内存账目，**不是总内存或 RSS**：不包含分配器元数据、共享源码
快照、解析索引、投影、贡献分片、UI 索引中的控件副本、图表/公式缓存、字体和 GPU。
`source_bytes` 是内容长度，不计入拥有内存总和。诊断开启后的扫描和日志本身也有成本，
不能直接把诊断运行的计时当作未启用时的生产延迟。

运行与汇总：

```sh
RYNE_PROFILE=1 cargo run --locked -- --smoke-test > /tmp/ryne-profile.log 2>&1
python3 scripts/summarize-profile.py /tmp/ryne-profile.log
```

汇总兼容原来的纯计时日志；计数取最终累计值，内存输出最终样本及各字段的观测峰值。
不同字段峰值可能出现在不同帧，不应相加当作同一时刻的总内存。

## 验证

- 目标与全量控件逐目标对照，覆盖表格对齐、空单元格、嵌套引用、嵌套列表、任务项、代码，
  并覆盖 LF / CRLF / CR。
- 大表格目标查询只返回一个控件；宿主测试证明目标执行不调用全量生成。
- enabled 实时改变、旧文档目标、源码模式、局部源码、目标回调错误/panic、畸形控件均拒绝；
  未迁移提供者仍执行全量验证。
- 大段替换后的历史字节查询能观察逆向正文，查询不影响 dirty、历史和撤销结果。
- 架构检查、格式检查、323 项全量测试、配套 stable Clippy 全目标检查及 diff 检查通过。
  macOS 原生窗口冒烟通过至阶段 374，启用诊断后观测到 253 次构建尝试、736 次缓存命中。
  这些是混合冒烟场景计数，不用于推算大文件延迟或提速比例；未运行 Windows 实机验收。
  完整结果见 [交付记录](reviews/architecture-2026-10-29/followup/first-batch/checks.json)，
  同目录保留测试、Clippy、原生窗口日志和 profile 汇总。

本批不处理 N2、R1、R5、R7，不改变导出冻结或装饰组合协议，也不实施大文件 P3–P5。
