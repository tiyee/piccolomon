# Ryne 左侧边栏架构与开发计划

2026-11-07 · 设计基线及实施验收记录。开发前的代码基线为 `2f4cd045ab`。

**每次成功打开文件，目录根自动切到这个文件的直接父目录。** 目录用于找文件，可在树形和带属性的文档列表之间切换。大纲用于浏览右侧当前文档的章节。窗口始终编辑一份 Markdown 源码，侧栏只拥有浏览状态。

## 1. 用户看到什么

| 入口 | 显示 | 主要操作 |
| --- | --- | --- |
| 目录 · 树形 | 根文件夹、可展开的子文件夹、文档名。当前文档用选中底色和左侧标线标识，键盘焦点另有轮廓。 | 单击文件夹展开或收起，单击文件打开。键盘上下移动，左右收起或展开，Enter 激活。 |
| 目录 · 列表 | 根及子目录下的文档。卡片上方为相对父目录和修改时间，中间为文件名，下方最多两行摘要。根内同名文件由路径区分。 | 默认按磁盘修改时间倒序，点击打开；按名称或相对路径筛选。 |
| 大纲 | 按源码顺序显示当前文档的 H1–H6，含 Setext 标题，以缩进表示层次。滚动正文时同步标识所在章节。 | 单击或 Enter 滚动至标题，保留编辑光标、选区和标题标记显隐。 |

工具栏右侧按钮组从左到右依次为侧边栏（收起时 `panel_right_expand.svg`，展开时 `panel_left_expand.svg`）、排版、视图／源码切换。按最终参考图，侧栏顶部居中显示“文件”或“大纲”。左上角图标切换两页，右上角搜索当前标题或文档列表。文件页底部显示根名称，左侧加号打开文件夹，右侧提供更多选项（含刷新）及树形／列表切换。配色沿用编辑器主题。目录空态提供“打开文件夹…”，文件菜单提供同一动作。筛选入口放在文档列表顶部。第一版的目录操作限于浏览和打开，文件管理、全文搜索、多标签及文件系统监听留给后续版本。

建议首次启动默认收起，首次展开已命名文档时显示目录树，无路径时显示大纲。用户显式切换后记住页签和视图偏好。切换页签保留同一根下的树展开、筛选和各视图滚动位置。新文件在后台成功打开时，即使侧栏收起或正在显示大纲，也立即更新逻辑根，等目录可见再发起读取。

## 2. 根目录与文档生命周期

### 同一窗口先后打开两个文件

假设两个路径相对于同一个起点。窗口正编辑 `a/b/c/d.md`，目录根为 `a/b/c`。用户选择打开 `e/f.md` 时，按以下顺序处理：

1. **等待期间继续显示 `d.md`。** 先确认正文 IME。如果 `d.md` 有未保存修改，提供“保存并打开”“放弃修改并打开”“取消”。取消就回到原编辑位置。选择放弃后也保留原会话，直到新文件成功安装。
2. **成功后在同一窗口切换。** 一次界面更新把正文、标题和大纲换成 `f.md` 的内容，目录根换成 `e`，当前文件标识换成 `f.md`。侧栏即使正在显示大纲，也要更新树形和列表共用的逻辑根。目录内容可以稍后加载。
3. **旧文件仍可重新打开。** `d.md` 的编辑会话随替换结束，其选区及撤销历史到此结束。在新文档按撤销只操作 `f.md`。旧文件保留在磁盘，也可在最近文件记录仍保留它时重新打开；重开读取当时的磁盘内容。

若从树中打开后代文件，窗口复用和切根规则相同。例如展开 `project/docs` 时仍以 `project` 为根，成功打开其中的 `guide.md` 后才切到 `project/docs`。同级文件共用一个父目录，成功打开兄弟文件时可直接更新当前行。

**系统入口。** macOS 和 Windows 采用相同的窗口内替换规则。冷启动从文件参数或系统打开事件得到初始文档；已有窗口收到系统文件打开事件时，将路径交给该窗口的替换流程并激活窗口。现有代码分别处理启动参数和运行期 `on_open_urls`。发布验收需用打包应用在 Finder 和资源管理器分别双击第二个文件。若某种文件关联启动了第二个进程，需要在该平台的启动入口把路径投递给已有实例，再由已有窗口执行未保存确认；该路径与冷启动分开验收。手动新建窗口、标签页和窗口偏好留作独立的产品需求。

### 各入口的状态变化

| 事件 | 何时生效 | 根、选中行及正文 |
| --- | --- | --- |
| 带文件参数启动 | 窗口拿到成功打开的初始 `Document` | 用已安装文档的显示路径设根。启动失败回退欢迎指南时进入无根状态。 |
| 文件菜单、最近文件、系统打开 URL、树或列表打开文件 | 现有替换流程完成 IME 确认、未保存确认、读取、回执与快照检查、草稿处理，并实际安装新文档后 | 始终取新路径的父目录。即使它是旧根的后代，也切根。同父目录仅更新当前行、大纲和必要的文件元数据，保留展开和滚动。 |
| 取消、读取失败、过期回执、等待保存或替换被阻止 | 结束本次替换，清除正在打开的行提示 | 窗口继续显示原文档。若此前已成功保存或首次绑定了原文档的路径，保留这次保存的磁盘内容、dirty 状态和相应目录根。 |
| 重新加载 | 成功安装重新读取的文档后 | 以加载文件的父目录为根，按新快照重建大纲。失败仍可继续编辑原文档。 |
| 手动“打开文件夹…” | 用户选定目录，后台初次枚举成功后 | 只换浏览根，正文、草稿和最近文件记录保留。若当前文档在该范围内，标识其路径；若在范围外，当前行留空。下次成功打开文件照常取父目录。取消或枚举失败留在原根。 |
| 首次保存、另存为 | 当前文档收到匹配的成功保存回执，已绑定所选显示路径 | 以保存后路径的父目录为根。即使保存的是较早修订且当前仍为 dirty，路径也已生效。失败、取消及外来回执保留旧根。 |
| 普通保存 | 成功回执后 | 就地刷新对应文件的时间与摘要。若用户已手动浏览别处，继续浏览该处。PDF 导出只产出文件，不触发文档路径事件。 |
| 新建未命名文档、恢复草稿、未保存的欢迎指南 | 安装无路径文档时 | 清除上一文档的自动根和选中行。若用户先主动打开了文件夹，可保留该手动根。大纲立即使用新文档的已提交内容。 |

**路径约定。** 根取自会话的 `files.path`。例如从 `notes/alias.md` 打开指向 `archive/a.md` 的链接，目录显示 `notes`，保存仍使用会话已有的目标绑定。CLI 的相对显示路径在入口按当时工作目录补为绝对浏览路径，再取父级；保留符号链接路径分量，用原生 `PathBuf` 比较和请求 I/O，只在绘制时转换显示文字。单个文件名、卷根、UNC 共享根、非 UTF-8 文件名分别测试。现有最近文件记录会规范化路径，从该入口打开时以它实际交给会话的路径为准。[现有路径绑定协议](42_File_Targets_And_History_Validation.md)

**选中与浏览分开。** 已打开行由当前文档显示路径派生。方向键只移动浏览焦点，待打开提示单独保存。激活与当前显示路径相同的一行只定位并返回正文，避免对正在编辑的文件重复弹出丢弃提示。文件已打开而父目录不可列举时，保留新文档和新逻辑根，侧栏显示目录级错误与重试入口。

### 文档事件如何接入

1. 启动时的 `Document::open → Editor::new` 与运行期的 `replace_document → install_document` 是两个入口。让两者把**已安装文档**交给同一个侧栏状态更新函数；成功恢复草稿也经过此处。欢迎指南随语言替换时按实际新快照更新大纲。[启动与系统打开入口](../crates/ryne-ui/src/lib.rs)
2. 侧栏行激活时核对绘制该行的根代次与条目路径，仍匹配才将显示路径传给 `Replacement::Path`，复用其串行、dirty、IME、后台错误和草稿保护。根和已打开行从安装结果更新。一次只接受一个替换请求，后续连点不积压“下一份文档”。
3. 在 `run_save` 调用 `complete_save` 后，只消费 `accepted && error.is_none()` 的结果。首次绑定或显示路径变化可由调用前后的路径判断。另存为选同一显示路径也属于显式另存为；为此让保存请求携带普通保存 / 另存为意图，意图随实际请求、排队替换和回执一起传递。UI 读取被接受回执的意图，避免使用一个会被后续请求覆盖的窗口布尔值。[串行保存请求](../crates/ryne-session/src/files.rs) · [保存完成逻辑](../crates/ryne-session/src/lib.rs)
4. “打开文件夹…”使用仅目录、单选的原生选择器。选择器和首次枚举携带一次选择请求身份。期间若成功打开了文件、选择了另一个目录或关闭窗口，迟到的选择结果失效。自动根在文档安装时发布；手动根在新目录可列举后发布，这两条路径分别处理权限错误。

### “保存并打开”的续接条件

当前 `replace_document` 在未保存时已有“取消 / 放弃并打开”，关闭窗口的提示已有保存选项。第二阶段在**打开另一个文件**的流程中补齐“保存并打开”，沿用串行保存和原子写入。文件菜单先选定目标文件，再询问如何处理当前文档；取消打开选择器即可返回编辑。

- 用户选择保存时，把目标文件、当前替换操作标识、原文档完整 `SnapshotId` 与本次保存请求关联。未命名文档先选择保存位置。原文档的保存和新文档的打开各用各自的回执。
- 只在本次保存成功、保存队列已空、原文档仍是确认时的快照、当前内容已保存且无预编辑时继续读取目标。保留已占用的替换操作，直接进入它的读取阶段；重复调用打开入口会被它自己的 pending 状态挡住。
- 取消保存位置、写入失败、保存期间又有编辑，均结束本次打开并回到原文档。若保存成功但新文件读取失败，原文档继续打开，已成功的保存照常生效。“放弃修改并打开”则只在安装新文档时生效，读取失败后仍可继续编辑和保存原来的修改。

## 4. 目录树、文档列表与后台读取

**读取端口。** 建议端口只有两类能力：枚举一个目录的直接子项，以及按上限读取一个普通文档的前缀。枚举接受取消检查、条目预算与批次接收器，返回完成、截断、取消或错误；接收器关闭也结束工作。每项返回原生名称、种类及可选修改时间/字节数。列表递归由同一目录枚举能力组合，文件打开仍交给文档服务。该边界允许测试指定批次顺序、读权限错误和迟到回执。

- **树形。** 展开才取一级，收起将对应分支从可见行序列移出。同一未完成请求去重，已完成分支在本根复用。文件夹优先，其次按名称排序，显示名称相同用原生路径作确定性次序。显示文件夹和可浏览文档，已成功打开的当前文件即使扩展名特殊也保留入口。
- **列表。** 首次切入列表才启动广度优先遍历。条目与树共用相对路径和元数据。修改时间相同用相对路径排序，时间未知的排在最后。后台批量归并排序，UI 以“首个可见路径 + 行内偏移”保留滚动位置，只创建可见行及少量相邻行。筛选只查询已发现的文件名/相对路径，忽略大小写。扫描途中标明结果仍在增加，清除筛选恢复完整列表。筛选输入不触发重新遍历磁盘。
- **文件与链接。** 首版默认文档类型取打包中已有的 `.md`、`.markdown`、`.mdown`、`.mkd`，另含 `.txt` 及无扩展名的 `README`、`LICENSE`，按名称规则忽略大小写。默认略过点开头的子项及 `target`、`node_modules`。用户显式指定的根本身照常列举。目录符号链接和 Windows 目录联接可标识但不进入递归；文件链接只允许普通文件目标，打开仍由文件会话核验。管道、设备及套接字排除。子目录不可读仅在该分支提示，其他分支继续。
- **摘要。** 名称和元数据先显示。只调度可见卡片及少量相邻项，从磁盘前缀取前两行非空可读文本作为预览，按两行裁切。遇 UTF-8 多字节截断仅去除末端不完整序列；中间解码失败或含 NUL 时显示文件元数据即可。当前打开文件有未保存编辑时，可见摘要直接取其已提交源码前缀，修改时间仍指磁盘。两种摘要分别按快照身份或文件路径、大小、修改时间与刷新代次校验。摘要既不运行全篇 Markdown 渲染，也不触发高亮、公式、图表或保存。
- **刷新。** 当前根手动刷新使同根旧结果失效；按需重取已展开分支，在列表可见时重新汇总。外部变化在刷新时反映。普通保存只失效所保存文件的元数据和磁盘摘要。目录消失可重试或另选文件夹，正文仍能使用会话已有的保存流程。

**工作预算建议初值**（实施时用实际语料校准）。

| 对象 | 初始限额 | 到达限额时 |
| --- | --- | --- |
| I/O 和回执 | 每窗口至多 2 个枚举任务、2 个摘要读取。每批最多 128 项，结果通道最多容纳 4 批。 | 优先可见树分支和可见摘要，队列满则后台等待。收起侧栏或离开列表时暂停新增递归和摘要任务。 |
| 目录遍历 | 每次列表扫描最多检查 50,000 项，最多深入 32 层；树主动展开每次最多检查 50,000 个直接子项。过滤掉的项也计数。 | 发布已发现的条目并提示“仅显示部分结果”，可打开更小的文件夹继续浏览。 |
| 条目缓存 | 树和列表每根共享最多 10,000 项，优先为当前文件保留位置。 | 停止累积列表结果。主动展开树分支时可回收仅树使用的非可见分支；无可回收项时显示截断提示。 |
| 摘要 | 每文件前缀最多 8 KiB。摘要缓存最多 256 项，文字合计最多 1 MiB。 | 淘汰近期未用摘要，可见项优先。切根释放旧数据。 |

**回执规则。** 返回 UI 的批次携带根代次、任务种类、请求序号和目标路径。刷新根、折叠后重开分支、快速 A → B → A 时旧任务至多结束自己的请求。取消在目录项之间、投递批次前和前缀读取前检查。慢磁盘上的单次系统调用可以稍后返回，用户界面不等待该调用。任务结束、错误或服务 unwind 都生成终态并清理对应的加载提示；关闭时断开接收端以释放等待发送的工作者。

## 5. 大纲的生成与跳转

1. 在 `SemanticQuery` 增加只读 `outline()`。从 `parse.semantic().index().heading_nodes` 按源码顺序取得解析器确认的标题，包含列表和引用内部的标题。每项保存 `level`、原文件 UTF-8 字节范围、首个正文锚点和可读标题。空标题用标题起点定位，由 UI 本地化显示“无标题”。用原文的 `SnapshotId` 标识整批结果；裸 CR 对应的语义视图另有身份，其等长换行映射须以原文范围边界校验。
2. 只遍历各标题自己的行内子树。粗体、斜体和链接贡献可读子文本，行内代码取字面值，图片取替代文字，公式取原 LaTeX，折行归一为空格。Setext 下划线和容器前缀不进入标签。代码围栏中的伪标题自然被排除。重名用不同源码范围区分；层级用最近的更浅标题作父项，遇 H2 → H4 不补造 H3。长标题按 grapheme 边界裁切显示，保留完整定位范围。
3. 按提交快照惰性生成并复用标题目录。侧栏隐藏或只显示目录时可推迟构建。大纲可见时编辑、历史操作或更换文档后按新身份更新；IME 预编辑期间继续显示最后一次提交的大纲，候选确认后合并更新。标题遍历的工作量随标题数及其子树大小增长，普通重绘和滚动不重新生成标题文字。
4. 行激活产生一次性跳转请求，包含原始 `SnapshotId`、标题范围和锚点。由下一次匹配的 `prepaint_frame` 通过当前 `IndexedDisplay::position_at` 与 `row_for` 找到视觉行，计入页顶边距，夹紧到可滚动范围，再消费请求。同帧显式跳转优先于旧的 `ensure_caret` 和宽度重排锚点。源版本过期即丢弃；局部源码、全文源码与渲染模式分别使用自己的当帧映射。仅更新视口滚动，光标、选区、显隐会话、源码和历史保留。靠近文末时以目标可见为通过条件。
5. 正向联动取视口顶部首个可见正文行的源码位置，对有序标题起点查找最后一个不大于该位置的标题。第一标题之前不标识章节；并排单元格同一高度取文档顺序的首项，独立图表可用其源码锚点。仅在活动条目变化时刷新高亮，程序更新高亮不会回发跳转请求。预编辑和正文拖选期间暂停大纲跳转与跟随。

## 6. GPUI 布局、焦点与输入

- **窗口结构。** 保留顶部整宽的平台标题栏，其下为侧栏与编辑区两列。文件名、排版和源码切换留在右侧工具栏，正文和状态栏随右列布局。默认宽度建议 260 逻辑 px，可调 200–360 px。若以首选宽度停靠后正文不足 460 px，切为覆盖面板；例如默认 920 px 窗口停靠，520 px 窗口覆盖。覆盖层只拦截内容区，文件成功打开或章节跳转成功后收起。回到宽窗口恢复首选宽度。按住分隔条期间每帧合并宽度更新，松手写入偏好。
- **几何。** 当前工具栏以整窗宽度计算 `theme::Page`，正文则用 `EditorElement` 的实际 bounds。改为两者共享右侧可用宽度，呈现模式仍按最大 760 px 居中。宽度或右栏原点变化前，从有效旧几何保存视口顶部的源码锚点与行内垂直偏移；新帧重新映射。给几何和渲染控件帧键增加内容区布局代次或等效的实际 bounds 校验。即使源码、展示内容、整窗大小相同，拖宽前的鼠标、弹窗和 IME 几何也应失效。新帧形成前暂停依赖旧坐标的命中。覆盖态只改变盖住区域的事件分发，右栏可维持原宽。
- **焦点。** 现有窗口根挂有 `MarkdownEditor`、编辑动作及 `capture_key_down(render_shortcut)`。将编辑专用上下文和捕获处理收窄到正文，让窗口级打开、保存、关闭与侧栏开关在两个面板都可用。树、大纲及筛选输入拥有各自焦点和键盘行为；滚轮只滚动指针所在面板。筛选输入提供独立的文本、选区和平台输入处理，支持中文 IME、剪贴板和 Escape。Escape 按“退出筛选 → 关闭覆盖层或返回正文焦点”处理。macOS 的窗口按钮区、Windows 的拖动区和窗口按钮继续由标题栏接收原生事件。[原生标题栏回归](../crates/ryne-ui/src/window_controls_tests.rs)
- **编辑保护。** 正文仍注册自己的输入处理器。组合输入期间暂缓侧栏拖宽、纯导航跳转与主动抢焦点；点击打开另一个文件仍由现有替换流程先确认 IME，失败就停止。筛选框中的候选确认 Enter 只提交筛选文字。正文拖选结束后再响应面板切换。侧栏的语言文案、空态、错误提示、时间与按钮提示覆盖现有七种语言，沿用应用配色和 SVG 资源机制。

### 可复现的性能样本

在仓库根运行 `cargo test --locked -p ryne-ui --lib large_directory_and_outline_sample -- --ignored --nocapture`。样本在临时目录建立 100 个子目录，每目录 100 份文档，另有包含 1,000 个标题的入口文档和一个忽略目录。测试摘要服务每次额外延迟 2 ms。以下为 macOS 15.8.1、920 × 680 GPUI 测试窗口、未优化且关闭调试信息的一次实测。耗时包含测试调度和绘制。

| 检查 | 观察结果 |
| --- | --- |
| 树形初次可用 | 91 ms，只枚举根一级 |
| 文档列表达到缓存上限 | 5.08 秒；共享目录 10,000 项，其中 9,900 份文档，显示截断提示 |
| I/O | 100 次枚举；扫描、筛选及滚动过程共读 219 份前缀。筛选产生 0 次新枚举。观测到的数据批次队列峰值为 1 |
