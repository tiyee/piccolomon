# 列表条目渲染操作实施记录

日期：2026-10-13。沿用 [20 · 扩展设计](20_Render_Mode_Interaction_Extensibility.md) 与
[21 · 表格操作通路](21_Render_Mode_Table_Interactions.md)，新增列表提供者，未增加会话或 UI 的业务命令分支。

## 界面与操作

有序、无序列表的每个条目在 hover/focus 时，在编号或圆点左侧显示 `more_vertical.svg`。
任务列表、嵌套与空条目沿用同一机制。
列表类型图标仅出现在整个外层列表右上角，随任意条目的 hover/focus 定位到同一列表，
类型菜单选择和复制完整列表；条目本身仅显示各自三点按钮，嵌套条目不重复显示类型图标。按钮按第一行实际行高居中；不会遮挡编号、正文或块类型入口，
也不改变正文宽度、自动折行及源码。首个内容为代码、表格等面板时，使用其源码映射定位入口。

点击打开七项分组菜单：

- 在后面添加条目、在前面添加条目：生成可直接输入的空同级条目，光标定位正文；任务条目使用未勾选标记。
- 上移条目、下移条目：只在同级之间移动，包含完整子树。
- 缩进、反缩进：复用现有结构算法，作用于点击目标及其子树。
- 删除条目及子项：删除目标子树，保留相邻条目、块和外部空行。

首项不能上移或缩进，末项不能下移，顶层条目不能用菜单反缩进。原有 Tab/Shift+Tab 和
Backspace 行为保留，包含顶层退出列表的原有路径。
菜单名称支持七种界面语言，图标来自现有 assets/icons。Alt+Enter 打开最内层焦点条目菜单，
方向键、Enter 和 Escape 使用已有通用菜单行为。点击按钮不先移动正文光标或替换选区。

嵌套条目、表格单元格与父条目的焦点/悬停区域重叠时，通用宿主优先更小的源码目标。
全文/对应局部源码、IME 预编辑及拖选期间隐藏控件；旧修订或旧布局无法执行当前操作。

## 实施边界

| 文件 | 职责 |
|---|---|
| `extensions/render_actions.rs` | `RenderControlPlacement::Leading/Trailing` 声明前置/后置位置 |
| `features/list_actions.rs` | 静态注册七种命令、条目目标、可用性、前置控件与真实子树范围 |
| `features/commands/list_actions.rs` | 插入、移动、删除与只读重定位候选；一次最终事务 |
| `features/commands/list.rs` | 提取现有按条目缩进函数，键盘和菜单共用算法 |
| `ui/layout_frame.rs` | 绑定条目及面板布局锚点，发布前置按钮和正文 hover 区域 |
| `ui/render_controls.rs` | 使用区域发布的按钮矩形，选择最内层焦点/hover，复用菜单与事件分派 |
| `ui/layout.rs` | 列表类型按钮定位整个列表右上角，保持实际首行对齐 |
| `ui/i18n.rs`、`ui/assets.rs` | 集中文案和已有 SVG 的嵌入 |

渲染宿主不识别列表命令 ID；计划仍由 `EditorSession::execute_render_action` 校验并经统一提交口发布。
没有新增可独立编辑的列表数据、单独历史或新依赖。前置位置属于宿主新增的通用布局能力，
并不表示任意未知布局都可以不提供区域就接入。

## 源码、选区与历史

列表 AST 可能包含尾部分隔空行。操作范围排除外部空白分隔，保留条目内部空行、完整容器前缀和代码区域，
防止移动最后一个条目后把后续段落吸入列表。候选提交前验证条目数量，结构不符合预期时不发布。

移动保留各个位置的原始编号/圆点标记；正文与子项整体移动。编号宽度跨越 9→10 时，
子项与代码容器缩进同步调整，代码字面正文保持一致；引用标记和容器空行不被意外改写。
LF/CRLF/CR、文末缺少换行和未涉及源码字节按原约定保留。

移动选区通过只读重定位候选映射，保持 UTF-8/grapheme 边界；候选本身不进入历史。
最终修改只有一个源码事务，撤销恢复原文、选区与检查点。插入空项若无法中断前面的段落，
会在同一事务中补必要的容器空行，避免生成 Setext 标题或普通段落中的假列表标记。
