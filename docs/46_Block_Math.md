# 块级公式

## 行为

独占段落的 `$$…$$` 使用解析器的 `DisplayMath`；单行和非空多行正文均可呈现，支持引用及列表。混在文字中、标题中、表格单元格中的双美元公式保留源码。单美元行为保持不变。

块公式在当前容器内居中，宽度不足时按比例缩小，保留完整 SVG。点击和左右方向键进入后展开完整公式源码，离开恢复预览；悬停不展开。局部／全文源码、拖选及 IME 使用现有显隐冻结规则。

独立输入 `$$` 后 Enter 提交一次补全事务，插入空正文行及闭合 `$$`，光标留在空正文。有效块公式正文 Enter / Shift+Enter 插入原始换行和容器前缀，不续列表／引用、不插入 Markdown 硬换行空格。正文粘贴保留容器上下文。源码模式不补全。

块图标和块菜单标题使用 `assets/icons/math_format_professional.svg`；快捷入口对齐整个内容区左侧，与普通段落入口同列，不随公式居中位置移动。嵌套公式继续共用外层容器入口。添加菜单新增块级公式，七语言欢迎指南包含可编辑示例。PDF 复用冻结数学服务与字体，矢量居中排版，正常尺寸整块分页，超页公式按可用区域缩小。

## 实现边界

- 源码仍是唯一数据真相。`SourceFormula` 持有 AST 节点、原文范围和正文范围，通过节点借用解析器去除容器前缀后的 LaTeX；不维护独立富文本正文。
- `FormulaRenderer::render_block` 默认不支持，未知提供者继续源码回退。正式服务使用 `MathDisplay::Block`，缓存及资源路径区分显示模式、字体和正文；旧行内资源路径保持兼容。
- 块公式以独占展示行的原子公式对象进入双向映射，校验器验证独占行条件。排版、命中、选区及绘制复用同一几何；跨范围编辑沿用源码事务。
- 沿用 4096 字节、嵌套、展开次数、MathML/SVG 大小及布局资源限制。转换警告、缺字、未知结构、CSS 依赖与自定义宏定义仍回退。
- 空白正文或跨空白段落的双美元表达式可能不被当前 Markdown 后端识别，此时保持可编辑原文。物理源码换行不自动产生数学对齐行。
- `matrix` / `pmatrix` 可用；`cases`、部分 `aligned` 等依赖 CSS 的布局不宣称支持，不删除警告或样式来伪装完整呈现。尚无公式编号、引用编号或二维编辑。
