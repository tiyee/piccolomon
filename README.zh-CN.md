# 如言（Ryne）——让 Markdown 写作自然呈现

[English](README.md)

如言是一款适用于 Windows 和 macOS 的原生桌面 Markdown 编辑器，适合日常笔记、技术文档与长文写作。正文在居中的阅读栏内自动折行，让你专注于文字本身。

在如言中，编辑与阅读融为一体。把光标移入粗体、斜体、删除线、链接或行内代码，格式标记就会展开。光标移开，文字恢复排版。点击标题即可修改标题标记。需要调整文档结构时，可以查看当前块的源码，也可以切换到全文源码模式。

- **直接编辑，保持结构。** 用 H1–H6 标题组织章节，在有序列表、无序列表、任务列表和嵌套引用中直接写正文。列表可以自动续项、调整缩进，点一下复选框就能勾选任务。
- **表格就地修改。** 点单元格即可输入，用键盘在格间移动。单元格菜单可以插入、移动或删除行列，也可以调整列对齐。
- **代码清晰可读。** 用行内代码写命令，用多行代码块放示例。输入起始围栏后按回车即可补全结束围栏。代码块可选择语言，支持 Rust、Python、JavaScript、TypeScript、JSON 和 Bash 语法高亮。
- **图表与公式随文呈现。** 在正文中预览 Mermaid 图表和行内 LaTeX 公式，点击即可编辑源码。要切换公式字体，选 **Ryne → 数学字体**。
- **整理与分享。** 一键整理 Markdown 排版，整次修改可以撤销。分享时可将表格、公式与 Mermaid 图表一起导出为分页 A4 PDF。
- **保留原始 Markdown。** 直接打开和保存本地 `.md` 文件，保留未修改内容的缩进与换行格式。可以跨行选择、复制粘贴，也可以撤销和重做。

如言提供简体中文、繁体中文、英语、日语、韩语、法语和西班牙语界面，每种语言都有一份可以动手编辑的使用指南。

从一段灵感到一篇完整文档，让思路如言而出。

## 安装与打开

- **Windows 10 或 11（x64）。** 下载文件名以 `win-x86_64.zip` 结尾的压缩包，解压后打开 `Ryne` 文件夹，双击 `Ryne.exe`。下载页面需要使用有仓库访问权限的 GitHub 账号登录。[下载如言](https://github.com/tiyee/ryne/releases)
- **macOS。** 如果你已拿到 `Ryne.app`，将它拖入“应用程序”文件夹后打开。也可以在访达中右键点按 Markdown 文件，选择**打开方式 → Ryne**。v0.2.6 发布页仅提供 Windows 下载包。

## 写第一篇笔记

1. 打开如言，先在欢迎指南上试着改几个字。想从空白页开始，选**文件 → 新建**；想接着写已有的笔记，选**文件 → 打开**。
2. 输入 `# 会议笔记`，按 **Enter**。在标题下输入 `- [ ] 发送会议纪要`，再点一下复选框，把任务标为完成。
3. 选择**文件 → 保存**，给笔记起个名字，例如 `会议笔记.md`，然后选择保存位置。下次可以从**文件 → 打开最近**找回这份笔记。

要保留原件并另存一份，选 **文件 → 另存为**。也可以从文件菜单重新加载磁盘上的版本。如言会在丢弃未保存的编辑前请你确认。

要切换菜单和欢迎指南的语言，选 **Ryne → 语言**。如言会记住你的选择，已经编辑过的指南会保留你的文字。

## 编辑常用格式

| 正在编辑 | 怎么操作 |
| --- | --- |
| 列表和引用 | 按 **Enter** 继续当前列表或引用。在空条目或空引用行再按一次 **Enter**，退出一层。列表里按 **Tab** 增加缩进，按 **Shift+Tab** 减少缩进。 |
| 表格 | 点单元格直接编辑。按 **Tab** 到下一格，按 **Enter** 到同列下一行，按 **Shift+Enter** 在格内换行。点单元格的 **⋮** 菜单可以插入行或调整列对齐。 |
| 代码 | 在行首输入三个反引号，接着输入语言名（例如 `python`），再按 **Enter**。如言会补上结束标记，你可以直接写代码。代码块上方的菜单可以切换语言。 |
| 图表和公式 | 将代码块语言设为 `mermaid` 可以绘制图表；在句子里输入 `$E=mc^2$` 可以写公式。光标移开后查看效果，点一下图表或公式就能继续修改。 |

不熟悉表格等格式的写法时，把鼠标移到文档末尾下方，点 **+** 即可插入。要在已有内容之间插入新块，把鼠标移到前一个块左上角的图标上，选择**在下方添加**。

要修改列表、表格或引用的 Markdown 标记，在同一菜单中选择**编辑块源码**。要查看整篇原文，点工具栏的**眼睛图标**；再点**代码图标**即可回到排版视图。图片和原始 HTML 以可编辑的源码显示。

## 保存与分享

- **保留原有格式。** 保存时会保留文件原来的换行符。想统一整理 Markdown 格式，可以点工具栏的**排版**。整次排版可以一步撤销。
- **导出 PDF。** 选择**文件 → 导出 PDF**，即可保存一份 A4 文档。如果需要可选中的正文和矢量公式，选择**导出 PDF v2**。导出后可以继续编辑原来的 Markdown 文件。
- **找回未命名的草稿。** 使用支持草稿恢复的版本时，意外退出后直接打开如言。如果出现草稿提示，选择**恢复**查看内容，再用**文件 → 保存**留存；选择**稍后处理**可以下次再恢复。
