# 如言（Ryne）

[English](README.md)

如言（Ryne）是一款原生 GPUI Markdown 编辑器：单窗口、单文档。光标进入行内格式时展开源码，
离开后隐藏标记并恢复样式。本项目交付桌面 GUI，不发布 crate。

Mermaid 围栏通过 Merman 0.7.0 支持原生彩色预览与源码编辑。
依赖兼容性、接入说明与选型实测见[渲染器评估](docs/13_Mermaid_Renderer_Evaluation.md)。

## 运行

需要当前 stable Rust（开发使用 Rust 1.99）；macOS 还需 Xcode 命令行工具，
Windows x64 还需 Visual Studio 2022/2026 Build Tools 的 C++ 桌面开发工作负载及 Windows 10/11 SDK。
GPUI 保持固定为 0.2.2。解析库使用已发布的
`editable_markdown_parser` 0.0.4，启用其可选公式 API。
启用 GPUI 的 `runtime_shaders`，无需额外下载 Metal 编译工具组件。

```sh
cargo run --locked
cargo run --locked -- /absolute/path/to/note.md
```

生成可双击启动的本地应用：`sh scripts/bundle-macos.sh`（调试版加 `debug`）。
结果为 `target/Ryne.app`，仅供本机使用，尚未公证或配置文件关联。
打包时从 `assets/logo.svg` 生成标准及 Retina 尺寸的 macOS 应用图标。
原地更新应用资源后刷新此应用的 Launch Services 注册信息。

Windows 使用 `pwsh -File scripts/bundle-windows.ps1`（调试版加 `-Profile debug`）。
产物为 `dist/Ryne-windows-x64.zip`，解压后运行 `Ryne/Ryne.exe`。
便携包静态链接 MSVC 运行库，并附带内嵌 STIX 字体的许可说明；发布构建会从
已安装的 Windows SDK 中寻找 `fxc.exe`，也可通过 `GPUI_FXC_PATH` 指定位置。
Windows 包尚未签名。

如果 Cargo 镜像尚未同步 editable_markdown_parser 0.0.4，使用官方 crates.io
源或等待镜像同步。

## GitHub Actions 打包

**Package desktop apps** 工作流在推送、拉取请求及手动 **Run workflow** 时运行。
使用锁定依赖生成发布包，检查架构边界和 Rust 格式，并将 ZIP 与 SHA-256 校验文件
上传到运行记录的 **Artifacts**，保留 14 天。

| 构建环境 | 架构 | 产物 |
| --- | --- | --- |
| macOS 15 | Apple Silicon / Intel | `Ryne-macos-15-{arm64,x86_64}.zip` |
| macOS 26 | Apple Silicon / Intel | `Ryne-macos-26-{arm64,x86_64}.zip` |
| Windows Server 2022 | x64 | `Ryne-windows-2022-x64.zip` |
| Windows Server 2025 | x64 | `Ryne-windows-2025-x64.zip` |

Runner 标签依据 GitHub 的[可用镜像](https://github.com/actions/runner-images#available-images)。
Windows Server 标签代表构建环境，两种包均面向 Windows 10/11 x64，并非分别对应桌面系统版本。
CI 打包不代表已验收 Windows 10/11 或旧版 macOS 上的 GUI、GPU 和输入法行为。
macOS 二进制部署目标与应用元数据均为 12.0，使用临时签名，尚未公证。
暂不提供 Linux 包。推送版本标签（例如 `v1.2.3`）会触发 **Release desktop apps** 工作流，
构建上述六种 ZIP 包，并将每个包及其 SHA-256 校验文件发布到 GitHub Release 页面。
标签包含连字符时（例如 `v1.2.3-rc.1`）会创建预发布版本。

另有 **Publish to Microsoft Store** 工作流，手动构建 Windows x64 MSIX，
并可选通过微软官方 Store CLI 提交更新。输入四段版本号，默认不勾选 `submit`，
可先检查产物；提交前需配置 Partner Center 身份 Variables 与认证 Secrets。
首次商店发布仍需在 Partner Center 完成，具体配置、命令和签名行为见
[Windows 商店发布说明](docs/19_Windows_Store_Publishing.md)。

## 编辑

- 顶部菜单提供 **Ryne → 关于、设置、检查更新、隐藏、退出**，以及
  **文件 → 新建、打开、打开最近、重新加载、保存、另存为、导出 PDF、导出 PDF v2**。
  macOS 使用原生应用菜单；Windows 在窗口顶部显示同一组命令。
  设置提供已有的语言偏好；最近文件持久保存最近十次成功打开/保存的路径，并可清除记录。
  新建、打开和重新加载在丢弃未保存内容前确认，等待期间继续编辑会阻止过期结果覆盖文档。
  检查更新查询 `tiyee/ryne` 的正式发布版本，并可打开发布页，不自动安装。
- PDF 导出基于不可变、标记收起的文档快照生成分页 A4 文件，支持系统字体回退、标题、
  行内格式、嵌套列表、代码背景、列对齐表格、公式及有效 Mermaid 预览。
  无效或不支持的结构保留当前源码回退。导出不改变文档路径、dirty、选区、历史或源码模式；
  导出前先确认输入法预编辑。引用、图片、原始 HTML 沿用编辑器当前的仅源码支持。
  限制源码 4 MiB、500 页，并沿用图表资源限制；缺失字体字形时报告错误，不静默丢字。
  长代码和表格内容折行并跨页继续。PDF 排版独立于窗口大小，代码使用普通样式，链接仅保留视觉样式。
  **导出 PDF** 保留原 svg2pdf 后端；**导出 PDF v2** 使用 krilla，默认文件名为 `文件名-v2.pdf`。
  两种方式共用 A4 分页、样式和快照保护；v2 嵌入可选择的正文文本及矢量公式，Mermaid 仍沿用位图预览。
  v2 尚未增加新的段落排版引擎、出版级分页或 Tagged PDF。
  无窗口导出示例支持 `cargo run --locked --example export-pdf -- INPUT.md OUTPUT.pdf --v2`。

- 界面支持简体中文、繁体中文、英语、日语、韩语、法语和西班牙语。
  点击工具栏“语言”即时切换，也可选择“跟随系统”；明确选择会在重启后保留
  （macOS 配置：`~/Library/Application Support/Ryne/language`），系统语言不受支持时回退英语。
  工具栏、块类型标题与菜单、表格和列表更多菜单（含列对齐子菜单）、添加菜单、文件提示、
  状态消息、默认指南和新插入块的占位文字均已本地化；菜单按译文、图标和快捷键宽度自适应。
  七种语言各自内置可编辑的默认指南，覆盖全部可用格式、操作说明与仅源码支持的限制
  （`crates/ryne-ui/assets/welcome`）。切换语言时，尚未编辑或保存的默认指南随之切换；
  已打开的文件、已编辑或保存的指南及其选区、撤销/重做和输入法预编辑状态保留。
  系统和渲染器的技术错误详情保留原文；
  原生文件对话框自带控件跟随 macOS 语言设置。
- 正文采用 Helvetica Neue 搭配苹方 SC 回退，18 px 字号，居中阅读栏最大宽度 760 px。
  标题使用半粗字重与分级字号，段落和块间距依据 Markdown 语义边界计算，源码空行仍可定位编辑。
  代码与局部/全文源码采用 15 px Menlo；字体不可用时回退至系统字体。
  纯排版不修改源码字节，也不产生 dirty。
- 光标高度随所在文字字号调整，输入法定位共用同一份光标几何。静止时每 500 毫秒切换显隐，
  输入、移动或重新聚焦后立即显示；输入法预编辑和拖动期间保持稳定，窗口失焦时隐藏。
  2 px 宽光标使用文字自然插入位置，不额外撑开间距或切开文字、删除线与行内代码背景。
  闪烁、焦点及选区变化保持折行稳定，鼠标命中与输入法定位共用排版，不修改源码或撤销历史。
- 文档内容末尾有一个不可见的添加区域；悬停区域显示 `+`，悬停或点击图标展开添加菜单。
  可快捷插入段落、H1–H6 标题、有序/无序/任务列表、引用、代码、Mermaid、表格、图片、
  行内公式和分隔线；插入后选中可替换的占位文字或将光标放入新正文。
  保留已有源码字节和所在位置的换行约定，整次插入可一次撤销；仅悬停不产生修改。
  拖选、输入法预编辑及全文源码模式下隐藏入口；末尾未闭合结构会吞入新块时提示先补全。
- 鼠标悬停块正文时，无需点击即可在左上角外侧显示淡灰色类型标识；编辑器获得焦点时，
  光标所在块也显示标识。类型包含 H1–H6、段落、列表、引用、图片、代码、Mermaid 和表格。
  标题、段落、有序/无序/任务列表、代码/原始块、图片和表格使用内嵌的 `assets/icons` SVG 图标；
  引用、Mermaid 和分隔线采用同风格的专用线性图标：引用竖线与缩进文字、流程图节点、水平分隔线。
  列表仅在整个外层列表右上角显示一个类型图标；各条目（含嵌套条目）只显示自己的三点按钮。
  列表类型菜单的选择与复制作用于完整列表。弹出菜单标题与块标识共用同一 SVG 类型图标。
  标识的垂直中心对齐块的第一行文字，代码块和表格以第一行正文为准。
  悬停标识展开菜单，点击菜单项可编辑块源码、选择整块或复制块源码；
  移开鼠标、Escape 或点击外侧关闭菜单。标识随嵌套、折行和滚动定位，
  拖选、输入法预编辑和全文源码模式下隐藏；显隐不修改源码或撤销历史。
  当前尚未提供块拖动与类型转换。
- 粗体、斜体、删除线、行内代码和链接支持行内预览。
  输入起始标记后，首个正文字符会在光标后补齐结束标记，并保持源码编辑状态。
  支持 `*` / `**` / `***`、`_` / `__` / `___`、`~~`、反引号、`[`（补 `]()`）及 `$`；
  遵循 Markdown 分隔符规则，转义或无效输入保持原文。输入自动补出的结束标记时直接越过，
  不重复插入。正文与补全可一次撤销；输入法确认后才补全，代码及局部/全文源码模式按字面输入。
- 单行 `$LaTeX$` 公式通过 math-core 0.5.5 转换、Formulary 0.3.0 就地渲染，内嵌 STIX Two Math 字形路径，
  支持基线对齐、自动折行和动态行高。点击或用方向键进入公式时展开字面源码，
  离开后恢复公式；列表和表格单元格沿用同一交互，代码内容保持字面显示。
  解析失败、超限、多行公式及 `$$...$$` 独立公式保留为可编辑源码。
  公式内中文等缺失字形、不支持的字体变体及 MathML 结构降级同样保留完整源码，避免丢字或误呈现。
  显隐和渲染不修改源码或产生 dirty；当前公式为单色，尚无二维结构编辑。
  保留独立的 [RaTeX / Formulary 历史对比](docs/reviews/formulary_renderer/README.md)，
  提供基线与 1×/2× 图片；RaTeX 已从编辑器依赖中移除。应用包包含 STIX 字体许可说明。
- H1–H6 与 Setext 标题使用对应字号、字重和行高；点击标题时展开其结构标记，
  光标离开标题后收起；仅悬停不展开。展开的 `#` 或下划线可直接编辑，也可使用全文源码模式。
  在块开头连续输入 1–6 个 `#` 时保留标记，输入首个非 `#` 字符后自动形成标题并收起标记；
  缺少的分隔空格随该字符一起写入，可一次撤销（如 `##标题` 自动保存为 `## 标题`）。
  代码及局部/全文源码模式保持字面输入。
- 点击或键盘进入行内元素，展开其源码和相关行内祖先；离开后收起。
- 普通段落支持多行编辑和自动折行。Enter 插入空行拆分段落，Shift+Enter
  插入 Markdown 硬换行（两个空格加换行），沿用所在位置的 LF / CRLF / CR。
- 在段首按 Backspace 或段尾按 Delete 合并相邻普通段落；拆分、合并及跨行
  替换均可一次撤销。支持跨行拖选、粘贴，以及保留目标列的上下移动。
- 有序、无序列表显示编号、圆点及嵌套缩进；正文和行内格式直接编辑，列表标记保持收起。
  自动折行及续行与正文对齐。Enter 续项，空项 Enter 退出一层；Shift+Enter 在项内硬换行。
  Tab / Shift+Tab 缩进或反缩进当前条目及子项（首个同级条目不能缩进）。
  正文开头 Backspace 反缩进或移除标记，正文末尾 Delete 合并相邻同级条目，保护相邻块。
  结构修改可一次撤销；项内多行粘贴延续容器缩进。
  悬停或聚焦条目时，编号/圆点左侧显示竖向三点 SVG；点击菜单可前后添加空条目、
  上下移动、缩进/反缩进、删除条目及子项，边界操作禁用。移动保留完整子树与编号位置，
  显隐不改变正文折行。Alt+Enter 打开当前条目菜单，方向键、Enter、Escape 操作菜单。
- Home / End 定位到当前显示行的首尾；自动折行不改变源码。
- 代码块支持反引号围栏、波浪号围栏与缩进语法：隐藏结构标记，显示语言标签、
  等宽正文与代码背景。代码中的 Markdown 按字面保留，支持空代码块及容器内代码。
  Enter / Shift+Enter 插入代码换行并延续缩进；正文边界删除不会误删围栏。
  输入反引号或波浪号起始围栏时保持源码可见，可继续填写语言；按回车后自动补齐同样的闭合围栏，
  光标进入空白代码行。补全可一次撤销，并保留容器缩进及 LF / CRLF / CR 换行。
- Tree-sitter 为围栏中的 Rust、Python、JavaScript/JSX、TypeScript/TSX、JSON 和 Bash
  提供语法高亮，支持 `rs`、`py`、`js`、`ts`、`sh` 等常见别名。
  编辑时更新高亮，局部与全文源码模式也保留代码正文高亮。
  粘贴代码或输入代码换行时，若现有语法能够确认有效且有明确特征的语言，自动补齐空围栏的语言字段。
  输入与补语言共用一次撤销；保留已填写语言，局部/全文源码模式按字面输入。
  有歧义、不完整或超过 32 KiB 的正文不识别；每次输入最多尝试八块，单次识别限时 50 ms。
  JSX 标记为 `javascript`。
  无语言、未知语言及缩进代码保持普通等宽样式。
  未变化的正文按语言缓存，移动块后重新映射源码位置；高亮不修改源码或撤销历史。
  单块超过 256 KiB 时使用普通样式；暂未实现语言注入及块内增量解析。
- 闭合的 `mermaid` 围栏在光标离开后显示彩色图表；点击或方向键进入后编辑字面代码，
  Escape 返回图表。局部与全文源码模式可修改围栏和语言字段；列表、引用中的图表保留
  容器前缀。选区、撤销和保存仍操作原始 Markdown，后台渲染及显隐不产生 dirty。
  无效、不完整或超限图表保留可编辑代码，渲染错误显示在语言标签旁；输入、图像与缓存均有上限。
- 管道表格显示网格、表头样式、列对齐及单元格自动折行；空单元格、正文和行内格式可直接编辑。
  Tab / Shift+Tab 切换单元格，Enter 移至下一行同列，超过末行时追加新行。
  Shift+Enter 在单元格内换行，以 `<br>` 保存；输入或粘贴的管道符自动转义。
  单元格边界删除保护列分隔符；列数不齐的表格保留可编辑源码，避免隐藏内容。
  悬停单元格或在其中编辑、选择文字时，右侧显示竖向三点 SVG 按钮；点击展开操作菜单。
  支持列对齐子菜单、前后插入行列、上下移动正文行、左右移动列、删除行列及边界禁用。
  按钮预留空间，显隐不改变折行；菜单不抢正文选区，每次修改可一次撤销。
  Alt+Enter 打开当前单元格菜单，方向键、Enter、Escape 操作菜单；行列快捷键在菜单中显示。
- 悬停块类型标识后选择“编辑块源码”，或将光标放入内容块点击“块源码”/按 Cmd+Shift+B，修改标题、列、对齐、列表标记、围栏及语言字段；
  再次切换或 Escape 返回预览。嵌套块的源码入口保留完整外层容器上下文。
- 引用、图片及其他未支持语法保留为可编辑源码。
  局部/全文源码模式及这些块内的 Enter / Shift+Enter 插入一个原始换行。
- 全篇共用一份源码、选区和撤销历史；查看源码不修改文件、不增加撤销记录。
- 使用原生打开/保存对话框；通过同目录临时文件及重命名保存原始源码，保留已有换行。
- 输入法预编辑保持临时状态，确认后通过一次源码事务提交。

## 内部架构

应用使用 9 个私有 Rust workspace 包，统一使用 `ryne-` 前缀：`ryne-app`、
`ryne-core`、`ryne-syntax`、`ryne-projection`、`ryne-extensions`、`ryne-features`、
`ryne-services`、`ryne-session` 和 `ryne-ui`。所有包禁止发布，可执行文件仍为 `ryne`。
根入口装配静态功能与类型化服务；只有 UI 包依赖 GPUI，源码事务、语义规则、投影和
后台任务可以脱离窗口测试。

会话验证只读命令计划，一次发布源码、匹配语义、选区和历史。输入规范化与补全共用草稿，
形成一次撤销。公式、图表、高亮和文件实现通过端口注入；图表宿主管理服务代次、取消、
资源预算及缓存内容与当前源码范围的重新绑定。保存串行后台执行，保存期间的新编辑仍为
未保存状态，旧保存成功不能关闭包含新修改的窗口。

依赖方向、验证范围与扩展限制见[实施记录](docs/18_Ryne_Architecture_Implementation.md)。
当前仍是静态内置功能的桌面应用，内部接口不作为公开插件 SDK 发布。

[渲染模式交互扩展设计](docs/20_Render_Mode_Interaction_Extensibility.md)描述渲染扩展贡献
自定义控件与命令的协议；[无窗口原型](docs/reviews/render_interactions/README.md)复用真实
会话与撤销系统验证操作链路。正式表格菜单已接入，实际边界见
[表格交互实施记录](docs/21_Render_Mode_Table_Interactions.md)。

## 检查

```sh
python3 scripts/check-architecture.py
cargo fmt --check
cargo test --locked
cargo clippy --locked --all-targets -- -D warnings
cargo run --locked -- --smoke-test
```

`--smoke-test` 打开真实窗口，验证排版命中、展开/收起、Unicode 输入、
输入法回调、撤销、模式切换、拆分/合并段落、硬换行、自动折行边界、上下移动、
跨行选择/替换、代码块排版与命中、围栏保护、空代码块与嵌套代码编辑、
代码块源码与语言修改、Tree-sitter 高亮、Unicode token 命中、编辑/撤销后的高亮更新与未知语言回退、
有序/无序/嵌套列表排版与命中、悬挂折行、
列表续项/退出/缩进、局部源码、跨项选区、表格对齐、折行/空单元格命中、
单元格导航、追加行、格内换行、嵌套表格与源码修改及保存/重开，
焦点/悬停块标识定位、悬停菜单与跨间隙保持（不移动光标）、复制/选择/源码操作、预编辑与源码模式隐藏及旧菜单目标保护，然后退出。
输入法回调检查不等同于各输入法候选窗口的人工验收。
自动检查忽略外部鼠标移动，以免人工操作干扰固定步骤；使用真实窗口几何调用编辑回调。
失败通过错误信息和退出码报告，不在原生事件循环中触发 panic。
可用 `cargo run --locked -- --smoke-test-failure` 验证失败路径，预期退出码为 1。

原架构文档和解析包检查报告保留在 `docs/`，其完整产品范围超出当前行内编辑 Demo。
